# 中文 Java 近义词典 v1.5
#
# 作用：集中维护全部中文关键字近义词，关键字表只引用组名，不写具体近义词。
# 格式：
#   组名=[近义词1，近义词2，…]
# 约定：
#   1. 组名即反译规范名，必须与 关键字表.txt 的中文侧写法一致；
#   2. 新增/删除近义词只改本词典，Cjc 下次运行自动生效，无需改关键字表；
#   3. 中文词在全表（含跨组）不得重复，由 Cjc 加载时校验；
#   4. 近义词参考《新华字典》释义与常用口语/书面语搭配；
#   5. 第 5 批已删除生僻/语义不准的近义词，只保留规范名与高频近义。
#
# 关键字表写法示例：public=[公有]  →  实际生效 公有、公开、公共。
