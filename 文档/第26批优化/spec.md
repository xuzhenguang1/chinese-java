# 第26批优化规格：`整数.值` 等装箱糖与第 8 课收尾

## 1. 目标

第 18 批已经把 `整数包装.解析` 简化成 `整数.解析`，但装箱一侧仍留 `整数包装.值`。本批补齐 `整数.值` / `长整数.值` / `双浮点.值` / `布尔.值` / `字符.值` 五个静态糖，让“解析”和“装箱”都只写基本类型名；同时把第 8 课最后一处内联数组拼接改成先声明数组再打印。

## 2. 发现的问题

| 编号 | 位置 | 问题 |
| --- | --- | --- |
| P1 | `方法糖.txt` | 已有 `整数.解析`，但没有 `整数.值`，按值删除只能写旧别名 `整数包装.值(2)` |
| P2 | `教程\第22课清单.java:9` | `数字清单.移除(整数包装.值(2))` 让学习者以为泛型必须用包装类 |
| P3 | `教程\第08课方法.java:31` | `打印行("平均值：" + 平均值(新建 双浮点[]{…}))` 把数组字面量塞进拼接，既不直观也偏离多实参写法 |

## 3. 变更明细

### 3.1 方法糖表新增五个静态糖

```text
整数.值=Integer.valueOf
长整数.值=Long.valueOf
双浮点.值=Double.valueOf
布尔.值=Boolean.valueOf
字符.值=Character.valueOf
```

静态糖条目 51 → 56。旧写法 `整数包装.值` 仍由成员糖 `值=valueOf` 兼容，不破坏已有代码。

### 3.2 教程调整

- 第 22 课：

```java
数字清单.移除(整数.值(2)); // 按值删除 2；若写 移除(2) 会按位置删除
```

- 第 8 课：把内联数组提成局部变量，打印改多实参：

```java
双浮点[] 样本 = 新建 双浮点[]{80.0, 90.5, 70.0};
打印行("平均值：", 平均值(样本));
```
