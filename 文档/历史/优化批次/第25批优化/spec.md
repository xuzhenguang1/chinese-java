# 第25批优化规格：标准库 `输出` 支持多实参拼接

## 1. 目标

`打印行("标签：", 值)` 是多实参写法，学习者已经习惯。但一旦改用标准库的 `输出.打印行`，就只能写回 `"标签：" + 值`——同一个“打印”动作出现两套写法。本批给 `输出` 补上 `Object...` 重载，让 `输出.打印` / `输出.打印行` 与语法糖行为一致，并清掉 `示例\标准库演示.java` 里最后 6 处拼接。

## 2. 发现的问题

| 编号 | 位置 | 问题 |
| --- | --- | --- |
| P1 | `标准库\输出.java` | `打印` / `打印行` 只接受单个 `Object`，多段文本只能手写 `+` |
| P2 | `示例\标准库演示.java` | 6 行仍是 `输出.打印行("标签：" + 表达式)`，与教程里统一后的多实参写法不一致 |

## 3. 变更明细

### 3.1 标准库新增重载

```java
public static void 打印(Object... 部分) {
    System.out.print(拼接(部分));
}

public static void 打印行(Object... 部分) {
    System.out.println(拼接(部分));
}

private static String 拼接(Object[] 部分) {
    StringBuilder 构建器 = new StringBuilder();
    for (Object 项 : 部分) {
        构建器.append(项);
    }
    return 构建器.toString();
}
```

- 只做追加，原有 `打印(Object)`、`打印行()`、`打印行(Object)` 全部保留，调用不受影响；
- `null` 拼接结果与字符串 `+` 一致（输出 `null`）；
- 纯 Java 实现，原生 javac 工程同样可用。

### 3.2 示例改写

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| 文本工具 4 行 | `输出.打印行("是否空白：" + 文本.是否空白("   "))` 等 | `输出.打印行("是否空白：", 文本.是否空白("   "))` 等 |
| 数值判断 | `"是整数：" + 数值.是整数("42") + " / " + 数值.是整数("4.2")` | `输出.打印行("是整数：", 数值.是整数("42"), " / ", 数值.是整数("4.2"))` |
| 时间 | `"现在：" + 时间.格式化(时间.此刻(), …)` | `输出.打印行("现在：", 时间.格式化(时间.此刻(), …))` |

### 3.3 单元测试

`标准库测试` 新增 `输出多实参依次拼接`：捕获 `System.out`，断言 `输出.打印` 不换行、`输出.打印行` 换行、无参 `输出.打印行()` 输出空行。换行符用 `System.lineSeparator()`，兼容 Windows 的 `CRLF`。
