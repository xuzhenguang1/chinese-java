# 优化批次总览（第 2–27 批）

本目录保存第 2–27 批优化的原始 `spec.md` / `tasks.md` / `计划.md`。这些文件是过程记录，结论已固化到 `CHANGELOG.md`、`语言规范.md`、`速查表.md` 与代码本身。

- 第 1、3 批没有独立文档目录。
- 完成于 2026-11-08 的第 28 批（`输出` 家族补齐）仍放在 `文档\第28批优化\`，待后续批次一并归档。
- 各批执行的固定流程：发现学习者痛点 → 小步修改 → 改前/改后编译运行对比 → 同步文档 → `cjc 检查` + `校验.ps1 -含原生` → 提交。

## 通用验收

每批结束都执行以下命令，结论均为退出码 0：

```powershell
.\cjc.ps1 检查 教程
.\cjc.ps1 检查 示例
.\工具\发布\校验.ps1 -含原生
```

涉及标准库的批次（第 9、25、28 批）额外执行 `mvn -f 标准库\pom.xml package`。
