# 第 15 批优化 · 规格与结果

状态：已完成

## 1. 目标

第 14 批做的是内部拆分；本批回到用户侧：**让人易学、代码更短、全中文写法**。
不改关键字表与近义词典，只做三件事：

1. **补两条新手最常用的糖**：`入口 声明抛出 …`、`清空` / `含值`。
2. **精简教程与示例代码**：集合字面量、泛型基本类型、入口写法，输出保持不变。
3. **改写入门文档**：README / 速查表 / 教程开头按「先能跑，再讲原理」重排。

## 2. 新增语法糖

| 写法 | 转译 | 说明 |
| --- | --- | --- |
| `入口 声明抛出 输入输出异常 { … }` | `public static void main(String[] 参数) throws IOException { … }` | 带 throws 的入口不用再写整段修饰符 |
| `清单.清空()` / `映射.清空()` | `.clear()` | 成员糖，来自 `方法糖.txt` `[成员]` |
| `映射.含值(值)` | `.containsValue(值)` | 成员糖 |

- `入口` 的识别条件从「后接 `{`」放宽为「后接 `{` 或 `声明抛出`」，改动只有 `isEntrySugar` 一处判断。
- `清空` / `含值` 只改 `工具\cjc\方法糖.txt`，`Cjc.java` 无内置表；方法糖表成员项 45 → 47。
