# 第 9 批优化 · 标准库与静态糖重复 API 收敛（Spec）

> 状态：已完成并发布 1.6.2（9.1–9.6）。
> 上游：第 8 批 Cjc.java 结构拆分完成，`.\工具\发布\校验.ps1 -含原生` 退出码 0。
> 方向（用户已确认）：**保留 `cjc` 静态糖作为唯一写法，删除标准库中重复的方法**。

---

## 一、重复清单（实测）

| 标准库 | 方法 | 对应的静态糖 |
| --- | --- | --- |
| `数学` | 绝对值 / 最大 / 最小 / 平方根 / 幂 / 取整 / 随机 / 圆周率 | `算术.绝对值` / `算术.最大` / `算术.最小` / `算术.平方根` / `算术.幂` / `算术.四舍五入` / `算术.随机` / `算术.圆周率` |
| `集合工具` | 排序 / 反转 / 打乱 / 最大 / 最小 | `集合助手.排序` / `集合助手.反转` / `集合助手.打乱` / `集合助手.最大` / `集合助手.最小` |
| `文本` | 格式化 | `字符串.格式化` |
| `数值` | 转整数 / 转长整数 / 转双浮点 | `整数包装.解析` / `长整数包装.解析` / `双浮点包装.解析` |

静态糖无法覆盖、因此保留：`集合工具.填充`、`文本.是否为空` / `是否空白` / `去空白` / `分割` / `重复` / `连接`、`数值.转文本` / `是整数`。

## 二、改动

1. 删除 `标准库\src\main\java\中文\标准库\数学.java`（唯一内容均为重复项）。
2. `集合工具.java` 只留 `填充`；`文本.java` 删除 `格式化`；`数值.java` 删除三个转换方法。
3. `标准库测试.java` 同步删改用例：数学用例整体删除，文本删除 `格式化` 断言，数值保留 `转文本` / `是整数`，集合工具改为只测 `填充`。
4. `方法糖.txt` 的 `[白名单]` 删除 `数学`，11 → 10 个类名。
5. `校验.ps1` 白名单计数改为 10；白名单反例由 `文本.格式化` 换成 `文本.去空白`。
6. `示例\标准库演示.java` 改用 `算术.*` / `集合助手.*` / `整数包装.解析` / `双浮点包装.解析`，删除 `数学` / `集合工具` 导入。
7. 当前生效文档（`README.md`、`AGENTS.md`、`速查表.md`、`语言规范.md`、`教程\教程.md`）同步删除 `数学` 与已删方法。

## 三、验收

```powershell
mvn -f 标准库\pom.xml test
.\cjc.ps1 编译 示例\标准库演示.java -d 构建\演示 -cp 标准库\target\cjc-stdlib-0.3.0.jar
.\工具\对话\运行.ps1 示例\标准库演示.java
.\工具\发布\校验.ps1 -含原生
```

- 标准库类数 11 → 10，白名单 11 → 10，词表与方法糖其余计数不变。
- `示例\标准库演示.java` 输出语义不变（绝对值 7、平方根 12.0、圆周率 3.14…）。
- 全量校验退出码 0。

> 说明：本批删除公开 API，属于破坏性变更；已随 1.6.2 发布（见 `发布说明-1.6.2.md`）。
