# 中文 Java v1.5.0 发布说明

发布日期：2026-11-06　关键字表：v1.5（56 个英文关键字 / 133 个中文词 / 34 个类型别名）　工具链：v1.5
VS Code 扩展：0.13.0　验证环境：Windows / JDK 25.0.2 / PowerShell 5.1

本次发布收口第 4 批留下的文档漂移，把近义词典从 235 词瘦到 133 词，并补上 JDK 14/17 的上下文关键字汉化。已有中文源码行为不变，仍可与英文 Java 混编。

---

## 1. 语言层新增

| 能力 | 写法 | 转译结果 | 说明 |
| --- | --- | --- | --- |
| 密封类 | `密封 接口 形状 许可 圆, 方 { … }` | `sealed interface 形状 permits 圆, 方` | JDK 17+；许可名单不加括号 |
| 解除密封 | `非密封 类 多边形 实现 形状 { … }` | `non-sealed class 多边形 implements 形状` | JDK 17+ |
| 切换表达式 | `情形 "金" -> 0.8;` | `case "金" -> 0.8;` | JDK 14+，箭头分支不写 `跳出` |
| 产出 | `默认 -> { … 产出 1.0; }` | `default -> { … yield 1.0; }` | 只能在切换表达式内部使用 |

`sealed` / `permits` / `non-sealed` / `yield` 与 `record` 一样属于上下文关键字：只走转译层，不写入原生补丁；VSCode 高亮、补全与悬停仍可用。规则细节见 [语言规范.md](语言规范.md) §4.20–§4.21。

## 6. 已知限制

1. `var` 仍未映射（可用 `--允许推断` 的 `令`/`常量` 间接使用）；`yield` 由 `产出` 转译；`record` / `sealed` / `permits` / `non-sealed` 分别由 `记录` / `密封` / `许可` / `非密封` 支持，均只走转译层、不进原生补丁。
2. 原生补丁与 JDK 版本绑定（当前 JDK 25），升级 JDK 后需重新生成。
3. 近义词典与关键字表须同目录；修改词表后需重新运行 `同步词表.ps1`。
