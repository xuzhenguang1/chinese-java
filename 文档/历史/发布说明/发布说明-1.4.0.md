# 中文 Java v1.4.0 发布说明

发布日期：2026-11-04　关键字表：v1.4（52 个英文关键字 / 236 个中文词 / 34 个类型别名）　工具链：v1.4
VS Code 扩展：0.12.0　验证环境：Windows / JDK 25.0.2 / PowerShell 5.1

本次发布不改语言内核与 51 个英文关键字，只补齐「对话式中文 Java」的写作糖、单文件运行闭环与编辑器内诊断建议；类型别名由 30 条增至 31 条（新增 `扫描器`）。已有中文源码与英文源码行为不变，可与英文 Java 混编。

---

## 1. 语言层新增（路线 A：`cjc` 预处理）

| 能力 | 写法 | 转译结果 | 说明 |
| --- | --- | --- | --- |
| 脚本模式 | 整份文件只写语句 | 自动包裹 `类 文件名 { 公有 静态 无 main(字符串[] 参数) { … } }` | 开头允许 `导入 …;`；诊断行号自动回映射 |
| 入口写法 | `入口 { … }` | `public static void main(String[] 参数)` | 省去修饰符与参数 |
| 字符串插值 | `"你好，{名字}"` | `"你好，" + 名字` | 支持属性/方法调用；`{{`/`}}` 转义；表达式含引号、冒号、逗号、反斜杠、换行时保持原样（保护 JSON） |
| 自动导入 | 不写任何 `导入`，或只写标准库导入 | 自动补 `import java.util.*;`、`import java.nio.file.*;`、`import java.io.*;`、`import java.util.stream.*;`、`import java.util.concurrent.*;`、`import java.util.logging.*;` | 写了其他导入或带 `包` 声明时不补；只导 Java 包，不导标准库 |
| 类型推断 | `--允许推断` 后用 `令 名称 = …` / `常量 名称 = …` | `var` / `final var` | 默认关闭，避免与教程「显式类型」教学目标冲突 |

规则细节见 [语言规范.md](语言规范.md) §4.7–§4.11。

## 2. 工具层新增

- **`cjc 运行`**：一条命令完成「检查 → 编译到临时目录 → 执行」，退出码透传。
- **`工具\对话\运行.ps1`**：单文件运行入口，缺省自动带 `标准库\target\cjc-stdlib-*.jar`；支持 `-类路径`、`-主类`、`-允许推断`。
- **模板库 `工具\对话\模板\`**（5 个，全部走 `入口`）：

  | 模板 | 适用场景 | 关键写法 |
  | --- | --- | --- |
  | 控制台程序 | 命令行小工具 | 循环 + `{序号}` 插值 + `参数` |
  | 增删改查 | 菜单式内存数据管理 | `链式键值表` + `Scanner` + `while (true)` |
  | 文件处理 | 读写/列举/删除本地文件 | `Path.of` + `文件` + 整段 try/catch |
  | 接口数据 | 调用 HTTP 接口 | `网络.取状态码` / `网络.取文本` |
  | 并发任务 | 线程池批量计算 | `并发.固定线程池` / `提交` / `取结果` / `关闭` |

- **`AGENTS.md`**：写给 AI 的硬约束（空格、标点、保留词替名）、模板选择与「对话式开发五问」流程。

## 3. 编辑器体验新增

## 6. 已知限制

1. `运行` 暂不支持向程序传参（只接受 `-cp`、`-主类`、`--允许推断`）；需要参数时请先 `编译` 再 `java -cp … 主类 参数`。
2. 自动导入只补 6 个 JDK 包；标准库（`文本`、`输出`、`时间`）仍需显式 `导入 中文.标准库.*;`。
3. 类型推断默认关闭，且只识别语句开头的「`令`/`常量` + 名称 + `=`」；必须带初始化式。
4. 字符串插值只展开简单表达式：含引号、冒号、逗号、反斜杠、换行或花括号时按字面量保留（用于保护 JSON、路径等）。
5. 原生关键字模式（路线 B）没有 CJK001/CJK002 专用诊断，粘连只表现为「找不到符号」；提交前仍建议运行 `cjc 检查`。
