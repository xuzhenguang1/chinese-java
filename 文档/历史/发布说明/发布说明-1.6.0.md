# 中文 Java v1.6.0 发布说明

发布日期：2026-11-06　关键字表：v1.6（56 个英文关键字 / 121 个中文词 / 34 个类型别名）　工具链：v1.6
VS Code 扩展：0.14.0　验证环境：Windows / JDK 25.0.2 / PowerShell 5.1

本次发布做结构收敛与语言面瘦身：把方法糖、诊断中文表外置为词表文件，拆开 `translate`，脚本去重，并删除长期零使用的成员糖、语法糖与语义不准的近义词。已有中文源码只要没用被删写法，行为完全不变。

---

## 1. 能力一览（不变）

| 能力 | 写法 | 转译结果 |
| --- | --- | --- |
| 入口 | `入口 { … }` | `public static void main(String[] 参数)` |
| 省略返回类型 | `公有 加一() { … }` | `public void 加一()` |
| 直接打印 | `打印行("姓名：", 名字)` | `System.out.println("姓名：" + 名字)` |
| 字符串插值 | `"你好，{名字}"` | `"你好，" + 名字` |
| 增强 for | `对于 (名 : 名单)` | `for (var 名 : 名单)` |
| 计数循环 | `重复 3 次 { … }` | `for (int 序号 = 1; 序号 <= 3; 序号++)` |
| 集合与流 | `清单` / `键值表` / `流` + `过滤` / `变换` / `收集` | `List` / `Map` / `stream` + `filter` / `map` / `collect` |
| JDK 14/17 汉化 | `记录` / `密封` / `许可` / `非密封` / `产出` | `record` / `sealed` / `permits` / `non-sealed` / `yield` |

## 2. 破坏性变更

1. **删除「名称前置声明」**：`计数器 类 {` 不再支持，统一写 `类 计数器 {`；`子类 类 继承 基类 {` 改为 `类 子类 继承 基类 {`。
2. **删除 9 个零使用成员糖**：`转小写`、`以结尾`、`取字符`、`全空白`、`替换全部`、`转字符数组`、`清空`、`含值`、`取下标`。需要时直接用英文方法名（`toLowerCase`、`endsWith`、`charAt`、`isBlank`、`replaceAll`、`toCharArray`、`clear`、`containsValue`、`indexOf`）。
3. **删除 12 个语义不准的近义词**：`种类`（class）、`包装`/`封装`（package）、`个人`（private）、`保障`/`维护`（protected）、`概念化`（abstract）、`持续`（continue）、`实验`（try）、`真正`（true）、`虚假`/`搀假`（false）。
   - `抽象` 组因唯一近义词「概念化」被删而移除，`抽象` 改在关键字表按单别名书写；词典由 51 组变为 50 组，中文词 133 → 121。
   - 回滚点：`文档\第6批优化\近义词典-1.5.txt`。

## 3. 工具链改进

- **方法糖外置**：`工具\cjc\方法糖.txt` 分 `[成员]` / `[声明]` / `[静态]` / `[白名单]` 四区，`Cjc` 启动时加载；`校验.ps1` 断言文件条数与内置默认表一致、白名单恰 11 个。
- **诊断中文化外置**：`工具\cjc\诊断中文表.txt` 约 60 条 `javac 正则 → 中文模板`，`Cjc` 表驱动本地化；`校验.ps1` 新增 12 条诊断反例。
- **`translate` 拆分**：拆为 `planSkip` / `planVoidAndPrint` / `planSugar` / `planCalls` / `planGenerics` / `planPrintArgs` / `renderTranslated`，重构前后转译结果逐文件 SHA256 一致。
- **脚本去重**：`工具\cjc\词表.psm1` 提供 UTF-8 读写、列表切分与词表解析，`同步词表.ps1`、`词典更新.ps1` 共用；`同步版本.ps1` 只替换版本号命名组，`-写入` 后自动复验。
- **VS Code 扩展 0.14.0**：关键字数据、高亮正则与词表同步重建。

## 6. 已知限制

1. `var` 仍未映射，可用 `--允许推断` 的 `令` / `常量` 间接使用。
2. `记录` / `密封` / `许可` / `非密封` / `产出` 只走转译层，不写入原生补丁。
3. 原生补丁与 JDK 版本绑定（当前 JDK 25），升级 JDK 后需重新生成。
4. 近义词典与关键字表须同目录；修改词表后需重新运行 `工具\cjc\同步词表.ps1`。
