## 3. 教学代码优化

### 3.1 `示例\打印多参数.java`

```java
公有 无 打印行(字符串 左, 字符串 右) {
    println(左 + 右);        // 改前：残留英文
}
```

改为：

```java
公有 无 打印行(字符串 左, 字符串 右) {
    打印行(左 + 右);         // 改后：语句开头的 打印行 会被糖改写成 System.out.println，不会递归
}
```

这样示例里不再出现英文 `println`，同时保留「带 `.` 前缀的 `器.打印行` 不被改写」这一教学点。

### 3.2 `教程\第22课清单.java`

变量名 `数值` 与标准库类名 `数值` 同名不同义（这里装的是清单），初学者容易读成「数字」。改为 `数字清单`（8 处引用）：

```java
清单<整数> 数字清单 = 数组清单.从(5, 2, 9, 2);
打印行("元素个数：{数字清单.元素数()}");
...
对于 (整数 项 : 数字清单) { ... }
```

输出文本保持不变（仍打印「数值合计」）。

### 3.3 `教程\第33课记录.java`

4 处字符串拼接改为插值，展示记录访问器也能直接放进 `{}`：

```java
打印行("{甲.姓名()}，{甲.年龄()} 岁");
打印行("同值对象相等：{甲.等于(乙)}");
打印行("转文本：{甲.转文本()}");
打印行("哈希码：{甲.哈希码()}");
```

### 3.4 `示例工程\src\main\中文\演示\应用\主程序.java`

手写三段式计数循环改为 `重复 N 次`（1 起算，正好匹配 `序号 = 1..学生人数`）：

```java
重复 学生人数 次 {
    整数 分数 = 60 + 序号 * 7;
    学生 学员 = 新建 学生("学员" + 序号, 分数);
    单.添加(学员);
    日志.添加("已录入：" + 学员.取姓名());
}
```
