## 三、任务明细

### 7.1 删除方法糖内置默认表（阶段一）

**现状**：`Cjc.java` 129–220 行有三张 `put` 表（成员 45 / 声明 3 / 静态 47），与 `工具\cjc\方法糖.txt` 完全重复；`loadMethodSugar` 在文件缺失时打印「使用内置默认表」并继续运行。

**动作**：
1. 删除 `MEMBER_CALLS` / `MEMBER_DECLS` / `STATIC_CALLS` 的全部 `put` 初始化，保留空 Map 字段，由 `loadMethodSugar` 从文件填充。
2. `loadMethodSugar`：文件缺失时打印中文错误并 `exit 2`（不再回退）；保留原有分区/格式/英文值校验。
3. `校验.ps1` 的 2.5.2 段：去掉「文件条数 == Java put 条数」断言，改为「文件存在 + 四区非空 + 英文值合法 + 白名单恰 11 个」，条数只打印。
4. 文档：`语言规范.md:34`「文件缺失时回退内置默认表」改为「文件缺失直接报错退出（码 2）」；`AGENTS.md:21` 同步一句话说明。

**验收**：
```powershell

```

**风险**：`Cjc.java` 不再能「单文件独立运行」（见决策项 1）。回滚：`git checkout -- 工具\cjc\Cjc.java 工具\发布\校验.ps1`。

5. `.\工具\发布\校验.ps1 -含原生` 退出码 0；关键字表、近义词典全程未变（仍为 v1.6 / 50 组 / 116 词）。
