继续面向学习者的优化：**把「解析字符串」这类高频操作从英文包装类名里解放出来**。不新增英文关键字映射，不改编译器内部结构。

### 3.2 为什么「关键字作接收者」可行

静态糖匹配用 `textAt(...)` 取**原始 token 文本**，不是翻译后的文本，因此 `整数`、`长整数`、`双浮点`、`布尔` 这些关键字式接收者能命中键；渲染时把 `类.方法` 整段替换为英文调用，关键字翻译被抑制。实测：

```java
打印行(整数.解析("42") + 1);
打印行(双浮点.解析("3.14"));
打印行(长整数.解析("100"));
打印行(布尔.解析("true"));
```

```text
43
3.14
100
true
EXIT=0
```
