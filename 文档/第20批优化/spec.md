# 第20批优化规格：插值支持括号内逗号 + 示例全面去拼接

## 1. 目标

让字符串插值真正覆盖「带参数的调用」，并把教程/示例里剩下的字符串拼接改成更短、更中文的插值写法。

## 2. 发现的问题

| 编号 | 位置 | 问题 |
| --- | --- | --- |
| P1 | `Cjc.isInterpolationExpression` | 花括号里只要出现逗号就不展开，`"最大值：{算术.最大(3, 9)}"` 会**原样打印**，不报错也不提示 |
| P2 | 教程/示例 | 多参数调用只能退回 `"前缀" + 表达式 + "后缀"`，拼接符号多、括号多，和「中文编程」的简洁目标不一致 |
| P3 | `语言规范.md` | 规则写的是「含逗号保持原样」，与学习者的合理预期冲突 |

P1 是**静默错误**：学习者不会收到诊断，只会看到一串 `{算术.最大(3, 9)}` 字面量，比报错更难排查。

## 3. 变更明细

### 3.1 `工具\cjc\Cjc.java`

`isInterpolationExpression` 增加括号深度跟踪：

```java
int depth = 0;
...
if (c == '(') {
    depth++;
} else if (c == ')') {
    if (depth == 0) {
        return false;          // 括号不配对，保持原样
    }
    depth--;
} else if (c == ',' && depth == 0) {
    return false;              // 括号外的逗号仍不展开，避免误伤 JSON / 枚举列表
}
...
return hasName && depth == 0;
```

效果：

- `{算术.最大(3, 9)}` → `Math.max(3, 9)`，可正常插值；
- `{文件助手.读所有行(目标).元素数()}` → 静态糖 + 成员糖一起生效；
- `{"键":"值"}`、`{甲, 乙}` 仍保持原样（引号 / 冒号 / 顶层逗号照旧拦截）；
- 括号不配对时也保持原样，不会生成坏代码。
