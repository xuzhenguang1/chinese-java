# 第22批优化规格：模板库全中文化

## 1. 目标

`工具\对话\模板\` 是学习者「说一句需求就生成程序」时最先复制的代码。其中仍有英文关键字、英文 API 与多余英文导入，本批把 5 个模板统一成纯中文写法，并顺便压缩重复循环与字符串拼接。

## 2. 发现的问题

| 编号 | 文件 | 问题 |
| --- | --- | --- |
| P1 | `控制台程序.java` | `for`、`if`、`println`、`参数.length` 全是英文；循环还写了三段式 |
| P2 | `接口数据.java` | `try` / `catch (Exception 出错)` / `println` / `正文.length()` / `出错.getMessage()` 全英文 |
| P3 | `文件处理.java` | 多余的 `导入 java.nio.file.*;`、`导入 java.io.*;`；4 行字符串拼接 |
| P4 | `增删改查.java` | 多余的 `导入 java.util.*;`；4 处 `否则 若`；3 行字符串拼接 |
| P5 | `并发任务.java` | 多余的 `java.util.*` / `java.util.concurrent.*` 导入；`长整数包装` 四面出现；三段式循环；3 行拼接 |

`导入 中文.标准库.*` 已会触发自动补 6 个 JDK 包（`java.util.*`、`java.nio.file.*`、`java.io.*`、`java.util.stream.*`、`java.util.concurrent.*`、`java.util.logging.*`），因此模板里再写英文导入纯属噪音。

## 3. 变更明细

### 3.1 `控制台程序.java`

```java
// 改前
for (整数 序号 = 1; 序号 <= 次数; 序号++) { println(...); }
println("参数个数：{参数.length}");
if (参数.length > 0) { println("第一个参数：{参数[0]}"); }

// 改后
重复 次数 次 {
    打印行("第 {序号} 次：你好，中文 Java");
}
打印行("参数个数：{参数.长度}");
若 (参数.长度 > 0) {
    打印行("第一个参数：{参数[0]}");
}
```

### 3.2 `接口数据.java`

```java
// 改前
try { … println("响应长度：{正文.length()} 字符"); }
catch (Exception 出错) { println("请求失败：" + 出错.getMessage()); }

// 改后
尝试 { … 打印行("响应长度：{正文.长度()} 字符"); }
捕获 (输入输出异常 出错) { 打印行("请求失败：{出错.取消息()}"); }
捕获 (中断异常 出错) { 打印行("请求被中断：{出错.取消息()}"); }
```

按 `网络.取文本` 的真实签名分别捕获 `IOException` / `InterruptedException`，比笼统的 `Exception` 更准确。

### 3.3 `文件处理.java`

- 删去 `导入 java.nio.file.*;`、`导入 java.io.*;`，只保留 `导入 中文.标准库.*;`；
- 4 行拼接改为插值：

```java
打印行("写入完成，大小 {文件.大小(目标)} 字节");
打印行("同目录文件数：{文件.列举(目标.取上级()).元素数()}");
打印行("删除后仍存在：{文件.存在(目标)}");
打印行("文件操作失败：{出错.取消息()}");
```

### 3.4 `增删改查.java`

- 删去 `导入 java.util.*;`（无任何导入时自动补 JDK 包）；
- `} 否则 若 (` → `} 否则若 (`，共 4 处；
- 3 行拼接改为插值：

```java
打印行("当前共 {学生.元素数()} 条：{学生}");
打印行("共 {学生.元素数()} 人");
打印行("未知命令：{命令}");
```

### 3.5 `并发任务.java`

- 删去 `java.util.*`、`java.util.concurrent.*` 导入；
- `异步结果<长整数包装>` → `异步结果<长整数>`（泛型实参自动换包装类），两处；
- 三段式循环 → `重复 10 次 { … }`；
- 3 行拼接改为插值。
