# 第 29 批优化：随机整数小工具（数值）

## 1. 目标

让学习者写“随机数”时不再需要强制转换与心算边界，代码更短、更中文：

- 改前：`打印行("随机整数：", (整数) (算术.随机() * 100));`
- 改后：`打印行("随机整数：{数值.随机整数(100)}");`
- 骰子：`数值.随机整数(1, 6)` 得到 1–6，含两端。

服务原有目标：易学、代码简单、中文化。

## 2. 现状与问题

1. `算术.随机` 只对应 `Math.random()`，返回 `双浮点` 的 `[0, 1)`。
2. 要得到整数必须写 `(整数) (算术.随机() * 100)`：既有多余的强制转换，又要自己判断“能否取到 100”。
3. 教程与示例中没有一处自然的随机整数写法，学习者容易写成 `算术.随机() * 100` 却忘了转型，或误以为能取到上界。
4. 现有 `数值` 类只做“转文本 / 是整数”，缺少最常用的随机整数。

## 3. 方案决策

在中文标准库 `数值` 中新增两个方法（不在 `cjc` 词表里新增静态糖，因为静态糖值只能是 `Math.abs` 这类点分标识符，无法表达 `ThreadLocalRandom.current().nextInt(...)`）：

| 写法 | 结果 | 说明 |
| --- | --- | --- |
| `数值.随机整数(上限)` | `1..上限`，含两端 | 最常见：`随机整数(100)` |
| `数值.随机整数(下限, 上限)` | `下限..上限`，含两端 | 骰子：`随机整数(1, 6)` |

实现使用 `ThreadLocalRandom.current().nextLong(下限, (long) 上限 + 1)` 后转 `int`，用 `long` 计算避免 `上限 + 1` 在 `Integer.MAX_VALUE` 时溢出；不引入额外边界分支。

非法入参抛 `IllegalArgumentException`（纯 Java 源码，消息用中文）：

- `随机整数(0)` → `上限必须大于等于 1：0`
- `随机整数(20, 10)` → `下限不能大于上限：20 > 10`

不新增关键字、不改词表、不升版本号；标准库 jar 版本仍为 `0.3.0`。

## 4. 变更清单（精确到文件与方法）

### 4.1 `标准库\src\main\java\中文\标准库\数值.java`

- 新增 `import java.util.concurrent.ThreadLocalRandom;`
- 类注释补一行：随机整数返回范围含两端。
- 新增两个 `public static int` 方法：

```java
public static int 随机整数(int 上限) {
    if (上限 < 1) {
        throw new IllegalArgumentException("上限必须大于等于 1：" + 上限);
    }
    return 随机整数(1, 上限);
}

public static int 随机整数(int 下限, int 上限) {
    if (下限 > 上限) {
        throw new IllegalArgumentException("下限不能大于上限：" + 下限 + " > " + 上限);
    }
    return (int) ThreadLocalRandom.current().nextLong(下限, (long) 上限 + 1);
}
```

### 4.2 `标准库\src\test\java\中文\标准库\标准库测试.java`

- `import static org.junit.jupiter.api.Assertions.assertThrows;`
- 新增测试方法 `数值随机整数范围与非法入参()`：
  - 循环 100 次断言 `数值.随机整数(6)` 落在 `[1, 6]`；
  - 循环 100 次断言 `数值.随机整数(10, 20)` 落在 `[10, 20]`；
  - 断言 `数值.随机整数(1, 1)` 恒等于 `1`；
  - `assertThrows(IllegalArgumentException.class, () -> 数值.随机整数(0))`；
  - `assertThrows(IllegalArgumentException.class, () -> 数值.随机整数(20, 10))`。

### 4.3 `示例\标准库演示.java`

在现有 `数值.是整数` 那一行之后追加两行（文件已 `导入 中文.标准库.数值;`，插值照常生效）：

```java
输出.打印行("随机整数 1–100：{数值.随机整数(100)}");
输出.打印行("掷骰子：{数值.随机整数(1, 6)}");
```

## 8. 风险与边界

- `计数` / `随机整数` 等新名不进入 `[成员]` / `[静态]` 糖果，不改变既有转译行为，零回归风险。
- 标准库为可选 jar，现有源码只要不调用新方法，行为不变。
- 不处理“随机数可复现（固定种子）”需求，避免过度设计。
