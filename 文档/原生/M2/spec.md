# M2 语义 + MIR + 解释器 Spec

- 状态：待批准
- 路线图：`文档\原生\路线图.md` 第 7 节 M2
- 前置：M1 已提交（35/35 解析成功、AST 快照、驱动与校验接入）

## 1. 目标

在 M1 的 AST 之上补齐语义层，并把语义结果降为可解释执行的 MIR：

1. 名称解析：变量、字段、方法、构造器、类、入口。
2. 类型检查：01–10 课涉及的基本类型、字符串、数组、类与重载。
3. 脱糖：字符串插值、复合赋值、自增自减、`重复 N 次`、增强 `对于`、`切换`。
4. MIR 文本格式：确定性、可快照、可直接作为 M3 降 C 的输入。
5. MIR 解释器：执行 01–10 课，stdout 与退出码与 JVM 后端逐字节一致。

## 2. 范围与边界

- 必须支持：教程 01–10 的全部语法与运行时行为。
- 保持 M1 能力：`原生 检查 教程` 仍为 35/35，AST 快照不变。
- 11–35 课：语义层可给出「M2 暂不支持」的中文诊断，但**不得崩溃、不得改动解析结果**；完整语义延到 M4/M5。
- 不实现：对象模型之外的 GC、异常处理器栈、标准库 C 运行时、泛型单态化、流式 API。

## 3. 设计

### 3.1 新增包 `中文.原生.中间`

| 文件 | 职责 |
| --- | --- |
| `类型.java` | 类型表示与赋值兼容、数值提升、装箱/拆箱判定 |
| `中间代码.java` | MIR 数据结构（sealed interface + record） |
| `语义分析器.java` | 名称解析、类型检查、脱糖，AST → MIR，诊断收集 |
| `中间打印器.java` | MIR 确定性文本输出 |
| `解释器.java` | MIR 解释执行、内建函数、运行时值与中文异常 |
| `解释器异常.java` | 解释器内部的中文运行时异常 |

`前端主程序` 增加 `中间`、`运行`、`对拍` 三个命令；`原生\驱动.ps1` 同步转发。

### 3.2 类型规则（01–10）

- 基本类型：`整数`/`短整数`/`字节`/`长整数` 归为整数族，`浮点`/`双浮点` 归为浮点族。
- 数值提升：整数族与浮点族混合时提升到浮点；`整数 / 整数` 保持整数除法（向零截断）。
- `字符串 + 任意`：另一侧按 JVM `String.valueOf` 规则转文本，`空` 输出 `null`。
- 比较与逻辑运算返回 `布尔`。
- 数组类型 `T[]`，支持 `.长度`；`新建 T[长度]`、`新建 T[]{…}`、`{…}` 初始化。
- 类类型：字段可读写，实例方法可调用；静态方法按「名称 + 实参个数 + 兼容度」选重载。
- 入口：脚本模式合成 `<脚本名>` 类的静态入口；类模式使用声明的 `入口`。
- 装箱/拆箱：类型层保留判定入口，01–10 无实际用例，M5 泛型时启用。

### 3.3 脱糖清单

| 源写法 | 降为 |
| --- | --- |
| `"姓名：{姓名}"` | `"姓名：" + 姓名`（按出现顺序拆分） |
| `甲 += 乙` | `甲 = 甲 + 乙`（其余复合赋值同理） |
| `甲++` / `--甲` | `甲 = 甲 + 1` / `甲 = 甲 - 1`（语句位置） |
| `重复 N 次 { … }` | `对于 (整数 序号 = 0; 序号 < N; 序号++) { … }` |
| 增强 `对于 (T x : 数组)` | `对于 (整数 i = 0; i < 数组.长度; i++) { T x = 数组[i]; … }` |
| `切换` 语句 | 等价的 `若 / 否则若 / 否则` 链（`情形` 依次比较） |
| `切换` 表达式 | 嵌套三目（无 `默认` 时报语义错误） |
| `否则若` | M1 已解析为嵌套 `若`，语义层不再处理 |

### 3.4 MIR 文本格式

确定性输出，两空格缩进，UTF-8 无 BOM、LF。示例（第 01 课）：

```text
程序
  类 第01课你好世界
    方法 <入口> 静态 无
      块
        表达式语句
          调用 内建 打印行
            常量 文本 "你好，中文编程！"
```

约定：

- 类型写在名称前；`方法 <入口> 静态 无` 表示入口。
- 调用按分派标注 `内建` / `静态` / `实例`。
- 常量保留字面量原文风格：文本带引号，字符带单引号，布尔 `真/假`，`空`。
- 字段、数组读、赋值、强制转换各占一行，子节点缩进。

### 3.5 解释器语义

- 输出：`打印行` 等价 `System.out.println`，多实参按 `+` 拼接；`打印` 等价 `print`。
- 浮点转文本使用宿主 Java 的 `Double.toString` / `Float.toString`，保证与 JVM 一致。
- 字符按字符输出；`布尔` 输出 `true` / `false`；`空` 拼接为 `null`。
- 内建：`打印行`、`打印`、`系统.数组复制`、`字符串.相等`、`修剪`、`长度`。
- 未捕获的运行时错误：输出中文诊断到 stderr，退出码 1。
- 未支持的 M2 外特性：输出 `M2 暂不支持：<特性>` 到 stderr，退出码 1。

## 4. 验收

```powershell
.\cjc.ps1 原生 中间 教程\第01课你好世界.java
.\cjc.ps1 原生 运行 教程\第01课你好世界.java
.\cjc.ps1 原生 对拍 教程
.\工具\发布\校验.ps1 -含原生
.\cjc.ps1 检查 教程
```

- `对拍`：01–10 课逐字节比较 stdout、退出码，输出 `10/10 一致`。
- MIR 黄金快照：`原生\测试\MIR快照\` 01–10 共 10 份，重复生成零差异。
- `校验.ps1 -含原生` 增加 M2 三项断言，仍输出「全部校验通过」。

## 5. 决策

- **D3**：M2 验收只对 01–10 课负责；11–35 课允许明确的「暂不支持」诊断，完整语义延到 M4/M5。
- **D4**：MIR 采用结构化文本（非扁平字节码），与 AST 同构但已定型、已脱糖，便于 M3 直接降 C。
- **D5**：对拍时 JVM 基准由 `cjc.ps1 编译` 生成 class 后直接 `java` 运行，只比较程序 stdout 与退出码，不混入编译日志。
