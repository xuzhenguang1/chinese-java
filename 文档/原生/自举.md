# 自举：词法层、语法层、语义层与中间码层

> 一期范围见 [ADR-011](ADR/ADR-011-自举一期范围.md)，二期见 [ADR-012](ADR/ADR-012-自举二期范围.md)，
> 三期见 [ADR-013](ADR/ADR-013-自举三期范围.md)，四期见 [ADR-014](ADR/ADR-014-自举四期范围.md)。
> 本文只写怎么用、边界在哪、验收看什么。

## 1. 是什么

`原生\自举\自举前端.java` 用中文 Java 重写了原生前端的四层：

- **词法（一期）**：读取 4 份词表（`关键字表.txt` / `近义词典.txt` / `方法糖.txt` / `诊断中文表.txt`），
  逐文件词法分析，产出 Token 流，诊断 CJK001（关键字与名称粘连）、CJK002（不可映射全角标点）、
  CJK106（句读折叠）。
- **语法（二期）**：递归下降解析出 AST，并按参考实现的缩进规则打印语法树；语法错误给出
  行、列、消息与建议。
- **语义（三期）**：在 AST 之上做名称解析（类、字段、方法、构造器、作用域）与类型检查
  （可赋值、子类型、方法/构造器匹配、返回值、条件、抛出/捕获、数组、三目），首错即停，
  只输出诊断消息，不生成 MIR。
- **中间码（四期）**：在语义检查之上把 AST 降级为 MIR（类、字段、构造器、方法、
  语句与表达式），用单一节点树与递归打印器输出与参考实现逐字节一致的 MIR 文本。

它不读第二份词表，也不复制词表；`工具\cjc\*.txt` 仍是唯一数据源。

```powershell

.\构建\自举\自举前端.exe 语法 E:\xiadujava 教程
```

## 3. 输出格式

### 3.1 分词

```
文件|<名称>
标记|<类别>|<行>|<列>|<原文>|<规范>
诊断|<错误|提示>|<码>|<行>|<列>|<长度>|<消息>|<建议>
汇总|<文件数>|<标记数>|<错误数>|<提示数>
```

- 类别取 `关键字 / 标识符 / 数字 / 文本 / 字符 / 符号 / 结束`。

### 3.2 语法

```
文件|<名称>
诊断|<错误|提示>|<码>|<行>|<列>|<长度>|<消息>|<建议>
树|<缩进>|<文本>
汇总|<文件数>|<解析成功数>|<诊断数>
```

- `缩进` 是空格数（两空格一级），`文本` 为该行节点描述。
- 语法命令只做词法诊断，不跑 CJK001 粘连检查与 CJK101–105 新手提示；
  词法有错时跳过解析，只输出诊断行。

### 3.3 语义

```
类|<全名>|<父类或 ->|<接口数>|<字段数>|<方法数>
字段|<类全名>|<名>|<类型文本>|<静态?真/假>|<只读?真/假>
方法|<类全名>|<名>|<参数类型1,参数类型2>|<返回类型>|<静态?真/假>|<抽象?真/假>
诊断|<行>|<列>|<码>|<消息>
汇总|<文件数>|<类数>|<方法数>|<诊断数>
```

- 类行、字段行、方法行各自按整行字符串自然排序；诊断按文件与插入顺序。
- 语义词法错误码统一为 `语义`；参考实现与自举侧都首错即停，只产生 1 条诊断，
  行、列固定为 0。
- 任一文件词法或语法出错时，只输出 `汇总|0|0|0|0` 并立即返回。

### 3.4 中间码

中间码直接输出 MIR 文本，与 `.\cjc.ps1 原生 中间 <文件>` 完全一致：

```
程序
  类 全名 [抽象] [枚举] [父 X] [实现 I1,I2]
    字段 类型 名
    静态字段 类型 名
      初值
        ...
    方法 名 静态|实例 返回类型
      参数 类型 名
      块
        ...
```

- 单文件不打印 `// 文件名`，多文件每份前打印；程序文本末尾追加一个空行。
- 每条语句/表达式一行，两空格缩进；`条件` / `则` / `否则` / `接收者` / `长度` /
  `初值` / `初始化` / `更新` / `体` / `捕获` / `兜底` 都单独成行并缩进一层，
  `捕获` 与 `兜底` 与 `尝试` 同级。
- 抽象方法体打印单行 `空语句`；降级失败时不输出 MIR，只打印错误与诊断消息。

四种命令的共同约定：

- 字段内 `\`、`|`、换行、回车、制表分别转义为 `\\`、`\|`、`\n`、`\r`、`\t`。
- 退出码恒 0；错误与提示只体现在输出与 `汇总` 计数里。

## 4. 能力边界

自举源码刻意避开原生后端尚未支持的 JDK API，替代写法如下：

| 缺口 | 替代 |
| --- | --- |
| 正则 | 手写 `拆行` / `切分词` / `是英文组名` |
| `Character.*` | 显式码点区间（`字符判定`） |
| `indexOf` / 单参 `substring` | `取子串(起, 止)` + `找字符` |
| 递归目录 | `文件助手.列举`（单层） |
| `List.sort` | 插入排序（`排序文本` / `按长度排序`） |
| 带副作用调用作接收者（`取().原文()`） | 先取到局部变量再访问（原生后端会重复求值接收者） |

三期口径：用户类严格按基类与接口做子类型判定；内置容器、包装类、标准库类、
泛型参数、λ、方法引用与数组初始化一律按「错误」类型放行，只保证不误报。

三期不做：MIR 降级、多文件语义、泛型实例化推断、λ 类型推断、`抽象类` 无实现校验、
替换生产路径的 Java 参考实现。

四期口径：MIR 降级覆盖教程 01–21 用到的全部声明、语句与表达式形态；接口降级为
`抽象` 类头，枚举自动生成 `转文本`，增强 for 与 `重复 N 次` 展开为临时变量，
插值与切换表达式/语句按参考规则脱糖。

四期不做：解释器与 C/LLVM 后端、教程 22–35 的降级、多文件共享符号表、
泛型实例化/λ/方法引用降级、替换生产路径的中间表示包。

自举源码另有四条写法约束（写 M10 时踩到并已规避）：中文关键字不能作标识符
（`切换` / `捕获` / `兜底` / `分支` / `真` / `假` 等）；字符串字面量不能含裸 `{`；
`&&` 右侧不能写 `是 T 名` 的绑定；局部变量必须带初值。

## 6. 已知限制

- 词法诊断之外的检查（CJK101–105）不在自举范围，两侧输出都不包含它们。
- `排序文本` 只按字符串比较升序，与参考实现的文件收集顺序在对拍中已验证一致；
  新增目录层级时需要重新确认收集顺序。
- 词表解析按行处理，`近义词典` 的组展开语义与 `词表.java` 等价，但实现不同；
  词表格式若变更，两侧需同时回归。
- 语法树节点类名与参考实现不完全相同，对拍只比较打印文本与诊断口径。
- 语义层按「用户类严格、内置与泛型宽松」实现：泛型实参、λ 与方法引用不做类型推断，
  内置容器与标准库调用只做存在性或实参个数检查；这些路径的误报风险由 35 课与
  20 条反例共同守住，新增内置类型时需要同步回归两侧。
- 中间码层只覆盖教程 01–21 的语料；22–35 课使用泛型、流、λ 与可变参数，
  降级器遇到未覆盖形态时抛出「不支持」并打印诊断，不产出 MIR。
