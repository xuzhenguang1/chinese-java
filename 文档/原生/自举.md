# 自举一期：词法层

> 范围与决策见 [ADR-011](ADR/ADR-011-自举一期范围.md)。本文只写怎么用、边界在哪、验收看什么。

## 1. 是什么

`原生\自举\分词器.java` 用中文 Java 重写了原生前端的词法层：

- 读取 4 份词表（`关键字表.txt` / `近义词典.txt` / `方法糖.txt` / `诊断中文表.txt`）；
- 逐文件词法分析，产出 Token 流；
- 诊断 CJK001（关键字与名称粘连）、CJK002（不可映射全角标点）、CJK106（句读折叠）。

它不读第二份词表，也不复制词表；`工具\cjc\*.txt` 仍是唯一数据源。

## 2. 怎么跑

```powershell
# 词表读数
.\构建\自举\分词器.exe 词表 E:\xiadujava

# 分词（单文件或目录，非递归）
.\构建\自举\分词器.exe 分词 E:\xiadujava 教程
```

仓库入口（会自动先编译前端与自举 exe）：

```powershell
.\cjc.ps1 原生 分词 教程          # 参考实现
.\cjc.ps1 原生 自举               # 自举对拍（编译 + 4 项断言）
```

单独的比对脚本：

```powershell
.\原生\测试\对拍分词.ps1
```

## 3. 输出格式

```
文件|<名称>
标记|<类别>|<行>|<列>|<原文>|<规范>
诊断|<错误|提示>|<码>|<行>|<列>|<长度>|<消息>|<建议>
汇总|<文件数>|<标记数>|<错误数>|<提示数>
```

- 字段内 `\`、`|`、换行、回车、制表分别转义为 `\\`、`\|`、`\n`、`\r`、`\t`。
- 类别取 `关键字 / 标识符 / 数字 / 文本 / 字符 / 符号 / 结束`。
- 分词命令退出码恒 0；错误与提示只体现在输出与 `汇总` 计数里。

## 4. 能力边界

自举源码刻意避开原生后端尚未支持的 JDK API，替代写法如下：

| 缺口 | 替代 |
| --- | --- |
| 正则 | 手写 `拆行` / `切分词` / `是英文组名` |
| `Character.*` | 显式码点区间（`字符判定`） |
| `indexOf` / 单参 `substring` | `取子串(起, 止)` + `找字符` |
| 递归目录 | `文件助手.列举`（单层） |
| `List.sort` | 插入排序（`排序文本` / `按长度排序`） |

一期不做：语法 / 语义自举、自举编译器编译自身、CJK101–105、替换生产路径的 Java 参考实现。

## 6. 已知限制

- 词法诊断之外的检查（CJK101–105）不在自举范围，两侧输出都不包含它们。
- `排序文本` 只按字符串比较升序，与参考实现的文件收集顺序在对拍中已验证一致；
  新增目录层级时需要重新确认收集顺序。
- 词表解析按行处理，`近义词典` 的组展开语义与 `词表.java` 等价，但实现不同；
  词表格式若变更，两侧需同时回归。
