# 自举：词法层与语法层

> 一期范围见 [ADR-011](ADR/ADR-011-自举一期范围.md)，二期范围见 [ADR-012](ADR/ADR-012-自举二期范围.md)。
> 本文只写怎么用、边界在哪、验收看什么。

## 1. 是什么

`原生\自举\自举前端.java` 用中文 Java 重写了原生前端的两层：

- **词法（一期）**：读取 4 份词表（`关键字表.txt` / `近义词典.txt` / `方法糖.txt` / `诊断中文表.txt`），
  逐文件词法分析，产出 Token 流，诊断 CJK001（关键字与名称粘连）、CJK002（不可映射全角标点）、
  CJK106（句读折叠）。
- **语法（二期）**：递归下降解析出 AST，并按参考实现的缩进规则打印语法树；语法错误给出
  行、列、消息与建议。

它不读第二份词表，也不复制词表；`工具\cjc\*.txt` 仍是唯一数据源。

## 2. 怎么跑

```powershell
# 词表读数
.\构建\自举\自举前端.exe 词表 E:\xiadujava

# 分词 / 语法（单文件或目录，非递归）
.\构建\自举\自举前端.exe 分词 E:\xiadujava 教程
.\构建\自举\自举前端.exe 语法 E:\xiadujava 教程

# 生成 AST 快照
.\构建\自举\自举前端.exe 快照 E:\xiadujava 构建\自举\快照 教程
```

仓库入口（会自动先编译前端与自举 exe）：

```powershell
.\cjc.ps1 原生 分词 教程          # 参考实现：词法
.\cjc.ps1 原生 语法 教程          # 参考实现：语法
.\cjc.ps1 原生 自举               # 自举对拍（一期 4 项 + 二期 3 项）
```

单独的比对脚本：

```powershell
.\原生\测试\对拍分词.ps1
.\原生\测试\对拍语法.ps1
```

## 3. 输出格式

### 3.1 分词

```
文件|<名称>
标记|<类别>|<行>|<列>|<原文>|<规范>
诊断|<错误|提示>|<码>|<行>|<列>|<长度>|<消息>|<建议>
汇总|<文件数>|<标记数>|<错误数>|<提示数>
```

- 类别取 `关键字 / 标识符 / 数字 / 文本 / 字符 / 符号 / 结束`。

### 3.2 语法

```
文件|<名称>
诊断|<错误|提示>|<码>|<行>|<列>|<长度>|<消息>|<建议>
树|<缩进>|<文本>
汇总|<文件数>|<解析成功数>|<诊断数>
```

- `缩进` 是空格数（两空格一级），`文本` 为该行节点描述。
- 语法命令只做词法诊断，不跑 CJK001 粘连检查与 CJK101–105 新手提示；
  词法有错时跳过解析，只输出诊断行。

两种命令的共同约定：

- 字段内 `\`、`|`、换行、回车、制表分别转义为 `\\`、`\|`、`\n`、`\r`、`\t`。
- 退出码恒 0；错误与提示只体现在输出与 `汇总` 计数里。

## 4. 能力边界

自举源码刻意避开原生后端尚未支持的 JDK API，替代写法如下：

| 缺口 | 替代 |
| --- | --- |
| 正则 | 手写 `拆行` / `切分词` / `是英文组名` |
| `Character.*` | 显式码点区间（`字符判定`） |
| `indexOf` / 单参 `substring` | `取子串(起, 止)` + `找字符` |
| 递归目录 | `文件助手.列举`（单层） |
| `List.sort` | 插入排序（`排序文本` / `按长度排序`） |
| 带副作用调用作接收者（`取().原文()`） | 先取到局部变量再访问（原生后端会重复求值接收者） |

二期不做：语义 / MIR 自举、自举编译器编译自身、把 CJK001 / CJK101–105 并入 `语法`、
替换生产路径的 Java 参考实现。

## 6. 已知限制

- 词法诊断之外的检查（CJK101–105）不在自举范围，两侧输出都不包含它们。
- `排序文本` 只按字符串比较升序，与参考实现的文件收集顺序在对拍中已验证一致；
  新增目录层级时需要重新确认收集顺序。
- 词表解析按行处理，`近义词典` 的组展开语义与 `词表.java` 等价，但实现不同；
  词表格式若变更，两侧需同时回归。
- 语法树节点类名与参考实现不完全相同，对拍只比较打印文本与诊断口径。
