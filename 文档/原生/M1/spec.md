## 1. 目标

为原生编译器实现独立的**词法分析 + 递归下降语法分析 + AST 文本打印**，覆盖 `教程\` 35 课全部语法，并把现有中文词表与新手诊断接入原生前端。

M1 只做前端，不做名称解析、类型检查、脱糖、MIR 与代码生成。

## 2. 输入与输出

| 项 | 内容 |
| --- | --- |
| 输入 | `教程\**\*.java`（UTF-8，中文 Java 源码） |

## 3. 语法清单（来自 35 课实测）

### 3.1 顶层

- 纯语句文件（01–07、19、22–24、27–29、31–32）：无类壳，按脚本模式解析。
- `类` / `接口` / `枚举` / `记录` 声明；嵌套类、成员内部类、静态嵌套类。
- `导入 包.*;`（解析并记录，M1 不校验包是否存在）。
- 修饰符：`公有` / `私有` / `保护` / `静态` / `最终` / `抽象` / `密封` / `非密封` / `默认` / `原生`；注解 `@覆写`。
- `类 X 继承 Y 实现 A, B`、`接口 X 许可 A, B`、`记录 X(分量…) 实现 Y`。
- `入口 { … }`、`入口 声明抛出 X { … }`。
- 泛型：`类 盒子<元素类型>`、`静态 <元素类型 继承 可比较<元素类型>> 元素类型 取较大(…)`、`新建 盒子<>("你好")`。
- 枚举常量带参数：`周一("工作日"), …;` 后接字段、构造器与方法。

### 3.2 语句

- `若 / 否则若 / 否则`（`否则若` 是单个标识符，需在解析层识别）。
- `对于` 三段式与增强 for；增强 for 可省略元素类型（`对于 (等级 : 清单.从(…))`）。
- `当`、`做 { … } 当 (…);`。
- `重复 N 次 { … }`、`重复 N 次 (名) { … }`、`重复 (表达式) 次 { … }`。
- `切换 (表达式) { 情形 … -> 表达式; / 块; 默认 -> … }`，表达式与语句两种用法。
- `尝试 / 捕获 (类型 名) / 兜底`。
- `返回`、`抛出`、`产出`、`跳出`、`继续`、局部变量声明、表达式语句、空语句。
- 局部数组：`整数[] 分数 = {…};`、`整数[][] 表格 = {{…},…};`、`新建 整数[长度]`、`新建 双浮点[]{…}`。
- 变量声明带泛型与菱形：`键值表<字符串, 整数> 库存 = 新建 链式键值表<>();`。

### 3.3 表达式

- 赋值与复合赋值：`=`、`+=`、`-=`、`*=`、`/=`、`%=`。
- 三目 `? :`；逻辑 `&&`、`||`、`!`；位运算与比较。
- `是` / `instanceof`，含模式绑定 `成员 是 销售 专属`。
- 强制转换：`(双浮点) 甲 / 乙`、`(点) 其它`、`(整数) (算术.随机() * 100)`。
- `新建`：对象、带泛型、数组、数组初始化器。
- 方法调用与链式调用、字段访问、数组下标、前后缀 `++` / `--`。
- Lambda：`名 -> 表达式`、`(名, 分) -> 语句`、`(名, 分) -> 打印行(…)`。
- 方法引用：`学生::总分`。
- 字符串插值与字面量保持原样（M1 不拆分插值）。

### 4.2 AST 模型

`语法树.java` 使用 Java 25 `sealed interface` + `record`，节点类别：

- 编译单元：导入、类型声明列表、脚本语句列表。
- 类型：类/接口/枚举/记录统一为 `类型声明`，用布尔字段区分；附修饰符、类型参数、父类、接口、许可列表、成员。
- 成员：字段、方法、构造器、入口、枚举常量、嵌套类型。
- 语句：块、若、对于、增强对于、当、做当、重复、切换、尝试、返回、抛出、产出、跳出、继续、局部变量、表达式语句、空语句。
- 表达式：字面量、标识符、二元、一元、赋值、三目、强制转换、实例判断、调用、字段访问、数组访问、新建对象、新建数组、数组初始化、Lambda、方法引用、前后缀自增。

类型引用统一表示为 `类型引用(名, 实参列表, 数组维数, 是否基本类型)`；中文类型名原样保留，不做英文替换。

### 4.3 AST 文本格式

- 每节点一行，两空格缩进。
- 节点头 = 节点名 + 关键属性（修饰符、名字、运算符、字面量原文）。
- 仅结构信息，不含绝对路径、时间戳、行号，保证快照可重复。
- 空块输出 `块` 单独一行；空参数列表不输出参数节点。

示例（第 08 课片段）：

```text
编译单元
  类型 类 第08课方法
    方法 静态 整数 求和
      参数 整数 甲
      参数 整数 乙
      块
        返回
          二元 +
            标识符 甲
            标识符 乙
```

## 5. 词表加载规则

与 `工具\cjc\词表.psm1` 保持一致：

- 忽略空行与 `#` 开头行；首行 BOM 剥离。
- `近义词典.txt`：`组名=[词1，词2]`，中英文逗号分隔；组名本身也是关键字。
- `关键字表.txt`：`english=[组名]` 或 `english=中文`；`[组名]` 展开为组名 + 全部近义词；同词首次出现优先。
- 类型别名区段单独解析，不进入关键字集合。
- 方法糖表按 `[成员]` / `[声明]` / `[静态]` / `[白名单]` 四区读取并计数；M1 只用于统计与后续复用。
- 诊断中文表只读取并计数；M1 的词法/语法诊断模板在原生前端内定义，因为现有 65 条面对的是 javac 消息。

## 6. 诊断口径

| 码 | 触发 | 输出 |
| --- | --- | --- |
| CJK001 | 标识符以关键字开头且剩余部分是已知标识符或多字关键字；`否则若(` 豁免 | 错误，退出码 1 |
| CJK002 | 无法映射的全角标点 | 错误，退出码 1 |
| CJK106 | `。` / `、` 已折叠为 `.` / `,` / `;` | 提示，不阻断 |
| CJK101 | 字符串用 `==` 比较（`== 空` 豁免） | 提示 |
| CJK102 | `x.整理()` 无参数 | 提示 |
| CJK103 | `读整数()` 后同一接收者紧跟 `读行()` | 提示 |
| CJK104 | 循环条件 `<= x.长度` / `<= x.元素数()` | 提示 |
| CJK105 | `/` 两侧均为整数（显式浮点强转豁免） | 提示 |

文案复用现有中文措辞；行尾含「忽略提示」时跳过该行提示。
