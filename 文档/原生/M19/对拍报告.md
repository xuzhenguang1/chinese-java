## 2. 能力层实证：后端同名类单测（G1 根治）

命令：

```bash
javac -encoding UTF-8 -d <临时类目录> \
  $(find 原生/前端/src 原生/中间表示/src 原生/后端C/src 原生/后端LLVM/src -name '*.java') \
  原生/测试/后端同名类测试.java
java -cp <临时类目录> 后端同名类测试
```

实测输出（退出码 0）：

```
  [通过] C 后端：甲.工具 全名符号存在
  [通过] C 后端：乙.工具 全名符号存在
  [通过] C 后端：同名类符号不同（根治）
  [通过] C 后端：全名编码覆盖多符号位置（甲 25 处 / 乙 22 处）
  [通过] C 后端：符号含各自包名编码
  [通过] LLVM 后端：甲.工具 全名符号存在
  [通过] LLVM 后端：乙.工具 全名符号存在
  [通过] LLVM 后端：同名类符号不同（根治）
  [通过] LLVM 后端：全名编码覆盖多符号位置（甲 16 处 / 乙 14 处）
  [通过] LLVM 后端：符号含各自包名编码
后端同名类测试：通过 10 / 失败 0
```

结论：两包同名类 `演示.甲$工具` / `演示.乙$工具` 在 C/LLVM 双后端产出**不同**全名 hex 符号（`演示`=`6f14_793a`、甲=`7532`、乙=`4e59`），覆盖构造/方法/静态字段/描述符多符号位置——G1 根治能力得证。这是端到端禁止同名类（G3）下唯一可行的实证路径。
