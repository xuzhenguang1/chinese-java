# M17 质量体系闭环 · 任务分解（tasks）

> 对应 `spec.md`。**分两批交付**：批次一（T0–T3，本机质量网，可独立提交）→ 批次二（T4–T5，双矩阵 CI，前置批次一绿）。

```
[批次一：本机质量网]
T0 ADR/文档/SHA256 ──→ T1 模糊.ps1 ──┐

[批次二：双矩阵 CI，前置①]
```

## 全局硬规则

1. **E1**：ASan 不可降级即失败；降级阶梯与边界必须写进 ADR-020。
2. **E4**：原定本地模拟未通过不改 CI 配置；本轮两批改动同在工作区、CI 配置先于完整 `CJK_*` 模拟写入，偏差已在 T4.4 记录并补跑通过。两批待用户确认后提交。
3. **ADR 先行**：先立 ADR-020、修订 008，再写脚本。
4. **零回退**：每批收尾都跑 `校验.ps1 -含原生`；本机 E: junction 路径参数化后照常工作。
5. **BOM**：所有中文 .ps1（模糊/内存/改动后的驱动与校验）写完确认 UTF-8 BOM（PS5.1 必需）。
6. **不入库二进制**：qemu/Alpine/musl 资产一律 `构建/` + CI 下载/cache，不提交。
