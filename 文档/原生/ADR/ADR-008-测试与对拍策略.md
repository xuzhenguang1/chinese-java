# ADR-008 测试与对拍策略

- 状态：已接受（M0；M17 修订测试矩阵口径与目录约定）
- 日期：2026-11-09（M17 修订 2026-11-22）
- 关联：路线图第 8、9 节；ADR-020（M17 质量体系闭环）

## 结论

原生实现的正确性以 **对拍** 为核心，辅以黄金快照、诊断一致性与内存检查：

1. **对拍**：同一中文源分别跑 JVM 后端与原生后端，比较 stdout 字节与退出码；stderr 只比较关键行。
2. **黄金快照**：AST 与 MIR 文本快照纳入仓库，文本必须确定性生成；改动快照需显式说明。
3. **诊断一致性**：`校验.ps1` 中的 13 条诊断反例与「缺标准库 jar」反例，在两套前端都要命中。
4. **模糊测试**：随机 Token 序列保证前端不崩溃、不挂起，并给出中文错误；固定种子、失败样本落盘可复现，只断言健壮性、不做输出对拍（M17 落地，详见 ADR-020）。
5. **内存检查**：Linux 按 ASan 优先 + 实测降级阶梯（静态分析 / GC poison / valgrind），musl 全静态 + 自建 GC 的边界与采用级别记录于 ADR-020；Windows 用 GC 压力用例与运行时断言（M17 落地）。
6. **性能基准**：递归 fib、长循环、字符串拼接、键值表读写，分别记录 JVM 与原生数据，不设硬性门槛（性能数值以本机为准，CI 不复现）。
7. **跨平台 CI**：Windows（clang / MSVC 至少其一）与 Linux（clang）双矩阵；ubuntu job 覆盖 ELF 全量对拍（历史 D3）；CI 与本机共用打包/VM/对拍脚本，资产下载 + cache + SHA256 校验（M17 落地，详见 ADR-020）。

目录约定：

```
原生\测试\
  对拍.ps1            单文件或目录的 JVM / 原生输出比对
  对拍原生.ps1         JVM / 原生 exe 输出比对（单后端）
  对拍ELF.ps1          35 课 ELF 全量对拍
  对拍浮点.ps1         浮点边界对拍（M16）
  模糊.ps1            随机 Token 健壮性断言（M17）
  内存检查Linux.ps1     Linux 内存检查（M17）
  检查调试信息Linux.ps1 DWARF 中文行号检查（readelf 可配置）
  运行器.ps1           Windows / Linux qemu VM 统一运行入口
  差异白名单.txt       允许不同的项（见 ADR-007）
  浮点已知差异.txt     浮点已知差异行级登记（M16）
  快照\               AST 与 MIR 黄金快照
  浮点边界\           浮点边界用例集（M16）
  工具\构建initramfs.py / 运行VM.py   ELF 运行资产工具
```

## 理由

1. 两套实现互为参考，比手写期望输出更能发现回归。
2. 黄金快照能在语义未跑通前先锁定「解析与降级是否稳定」。
3. 诊断一致性直接复用现有资产，避免新前端重新发明错误文案。
4. 模糊测试成本低，能提前暴露词法与语法边界的崩溃。

## 替代方案

| 方案 | 不采用的原因 |
| --- | --- |
| 只写单元测试、不做对拍 | 无法验证两套实现的最终行为一致 |
| 只比较退出码 | 无法发现输出内容回归 |
| 手写期望输出 | 35 课与标准库规模下维护成本过高 |

## 验收口径

- M0：`.\工具\发布\校验.ps1 -含原生` 退出码 0，且新增的 M0 检查项全部通过。
- M2 起：01–10 课对拍 0 差异（白名单除外）。
- M3 起：Windows 与 Linux 各跑一遍 01–08 课。
- 每次里程碑结束，快照可重复生成，差异为零。
- **M17 起**：`校验.yml` 双矩阵（windows-latest + ubuntu-latest）均绿；ubuntu job 完成 ELF 全量对拍（35 课 C/LLVM + 示例工程 + 自举不动点 + DWARF + GC + 网络冒烟）；模糊固定种子 N 轮健壮性三断言通过；Linux 内存检查按 ADR-020 的 E1 当前阶梯通过、对应工具无 leak/overflow；白名单与已知差异逐条可追溯到 ADR 锚点。性能基线仍以本机为准，CI 不复现。

## 影响

- 对拍脚本必须能同时调用 JVM 链路与原生链路，且不污染用户工作目录（中间产物放 `构建\`）。
- 快照文件与白名单文件属于测试资产，随代码提交；临时产物不入库。
