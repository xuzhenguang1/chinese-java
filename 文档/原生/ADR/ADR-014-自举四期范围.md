# ADR-014：M10 中间码自举范围（MIR 降级与打印）

- 状态：已采纳
- 日期：2026-11-16
- 关联：路线图第 7 节 M10、ADR-004（中间表示与 MIR 文本格式）、ADR-008（测试与对拍）、ADR-013（自举三期范围）

## 背景

三期（ADR-013）已验证名称解析与类型检查可以自举，但自举前端仍停在「只判对错」。
M10 的目标是把教程 01–21 的 AST 降级为 MIR 并打印成与参考实现逐字节一致的文本，
验证「中文 Java 能写编译器的语义层与中间码层」。

MIR 是本项目与后端之间唯一的稳定契约（ADR-004），因此把 M10 的验收面收敛为
「降级结果 + 打印文本」，不碰解释器、C 后端与 LLVM 后端。

## 决策

### 1. 四期范围 = MIR 降级与打印自举

- 在 `原生\自举\自举前端.java` 内追加 MIR 层：`中间节点` 树、递归打印器、
  `语义检查器.中间(单元, 名称)` 降级入口，以及与参考实现同口径的 `中间` 命令。
- 复用三期的类表、字段表、方法表、构造器表与作用域，不重建符号系统。
- 不替换生产路径的 Java 语义分析器与中间表示包；参考实现继续作为对拍基准。

### 2. 参考口径是既有的 `原生 中间` 子命令

- `.\cjc.ps1 原生 中间 <文件>` 已有固定输出：单文件不打印 `// 文件名`，
  多文件每份前打印；程序文本每条语句/表达式换行、两空格缩进，末尾追加空行。
- 自举侧 `自举前端.exe 中间 <根> <文件...>` 复用同一格式，逐字节对拍。
- 两个命令的输出差异只允许来自降级结果，不允许改造打印格式。

### 3. 自举侧数据结构：单一节点 + 标签行

```java
类 中间节点 { 字符串 头; 数组清单<中间节点> 子们; 语义类型 结果类型; }
```

- `头` 即完整行文本（如 `二元 文本 +`、`调用 内建 打印行`）；
- `条件` / `则` / `否则` / `接收者` / `长度` / `初值` / `初始化` / `更新` /
  `体` / `捕获` / `兜底` 也是只带一个子节点的中间节点；
- 打印器只做两件事：写当前行、对子节点缩进一层；`捕获` 与 `兜底` 是
  `尝试` 的同级行，打印时回退一层；
- 空语句统一打印 `空语句`，与参考打印器的 null 分支一致。

### 4. 降级口径逐项对齐参考实现

| 项 | 口径 |
| --- | --- |
| 类头 | `类 全名 [抽象] [枚举] [父 X] [实现 I1,I2]`；接口降级为 `抽象` 类头 |
| 类内顺序 | 字段 → 静态字段（下挂 `初值`）→ 枚举常量（实参直挂）→ 构造器 → 方法 |
| 抽象方法 | 体为单行 `空语句` |
| 构造器前置 | 每条前置包 `表达式语句`：`__外部` 赋值、字段初值赋值 |
| 默认构造器 | 仅当无构造器声明且存在字段初值时合成，名为 `<构造>` |
| 枚举 `转文本` | 仅当未声明时生成，体为直接子节点 `返回`（非块），读 `__枚举名` |
| 临时变量 | `临时序号` 每类静态初始化重置；字段初始化延续；方法/构造器保存、重置、恢复 |
| 增强 for | `__容器N` + `__下标N`，初始化是含两个 `变量` 的块，条件用 `数组长度` |
| `重复 N 次` | 初始化是单个 `变量 整数 序号`（不包块），条件 `<=` |
| 插值 | 首个表达式前补 `常量 文本 ""`，左结合 `二元 文本 +` |
| 切换表达式 | 嵌套 `三目`；切换语句 → 嵌套 `若` 链，分支结果直挂 |
| `x 是 T 名` | 块内两个变量（来源、绑定），绑定值用 `三目` + `强制转换` |
| 数字常量 | `L/l` 长整数；`F/f` 浮点；`D/d` 或含 `.` 双浮点；否则整数 |
| 一元 `~` | 字节/短整数/字符提升为整数，其余保持 |
| 复合赋值与自增 | `赋值 左类型`，右为 `二元 计算类型 基础`，左节点复用 |

### 5. 四期不做

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 解释器与 C/LLVM 后端 | 不做 | M10 只验证到 MIR 文本 |
| 教程 22–35 的降级 | 不做 | 超出本期内核定稿的 01–21 语料 |
| 多文件共享符号表 | 不做 | 与参考一致：逐文件独立分析 |
| 泛型实例化、λ、方法引用降级 | 不做 | 01–21 未使用 |
| 替换生产路径的中间表示包 | 不做 | 参考实现继续作为对拍基准 |

### 6. MIR 快照即黄金基准

- `原生\测试\MIR快照\` 存 21 份 `第01–21课*.mir.txt`（LF、UTF-8 无 BOM），
  由 `.\cjc.ps1 原生 中间 <文件>` 逐文件生成。
- `原生\测试\对拍中间码.ps1` 负责：教程 21 课（2193 行内容）自举 vs 参考逐字节对拍、
  21 份快照对拍，输出「通过 2 / 共 2 项」；退出码非 0 即失败。
- `原生 自举` 串联第四项；`校验.ps1` 新增 8.9 断言。

## 备选方案与取舍

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| 直接生成自定义 IR 再转打印文本 | 未采纳 | 与参考打印器双实现，差异难归因 |
| 每个节点类型一个类 | 未采纳 | 节点种类多、字段少，单一节点树更贴近打印器 |
| 先做 C 后端再做自举 | 未采纳 | 后端不验证语义自举，范围失控 |
| 支持 22–35 课全部语法 | 未采纳 | 泛型/流/λ 降级成本高，本期不设目标 |
| 打印器改写换行符为 LF | 未采纳 | 与 M8/M9 一致：对拍按行归一化 CRLF |

## 影响

- `原生\自举\自举前端.java` 新增 MIR 降级、打印器与 `中间` 命令（单文件继续自举）；
- `原生\测试\MIR快照\` 21 份基准、`原生\测试\对拍中间码.ps1`；
- `原生\驱动.ps1` 的 `自举` 串联第四项；`校验.ps1` 新增 8.9；ADR 计数 13 → 14；
- 自举源码需规避中文关键字作标识符（`切换`/`捕获`/`兜底`/`分支`/`真`/`假`）、
  字符串字面量含 `{`、`&&` 右侧的 `是 T 名` 绑定、局部变量必须初始化等既有约束。

## 验收

1. `自举前端.exe 中间 <根> <文件>` 对教程 01–21 与参考实现逐字节一致
   （21 份、2193 行内容）；
2. `原生\测试\MIR快照\` 21 份与自举逐文件产物逐字节一致；
3. 一期 `对拍分词.ps1`、二期 `对拍语法.ps1`、三期 `对拍语义.ps1` 不回归；
4. `.\cjc.ps1 原生 自举` 四项全绿；`.\工具\发布\校验.ps1 -含原生` 退出码 0。
