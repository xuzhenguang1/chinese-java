# ADR-012：M8 自举二期范围（语法层）

- 状态：已采纳
- 日期：2026-11-13
- 关联：路线图第 7 节 M8、ADR-008（测试与对拍）、ADR-011（自举一期范围）

## 背景

一期（ADR-011）已验证「中文 Java 能写出词法层并产出独立 exe」：Token 流与诊断
与 Java 参考实现逐字节一致。二期把同一份自举源码向上扩一层，覆盖**语法分析
与 AST 文本打印**，用来验证「中文 Java 能写出编译器前端的主体部分」。

二期仍不做语义分析与自举自举：语义层依赖名称解析、类型检查与多文件语义，
会同时引入大量 JDK API 缺口，无法把「自举 bug」与「编译器 bug」分开定位。

## 决策

### 1. 二期范围 = 语法自举

- 在同一单文件内追加 AST 节点、递归下降语法分析器、AST 打印器与 `语法` / `快照` 子命令。
- 一期文件 `原生\自举\分词器.java` 更名为 `原生\自举\自举前端.java`，词法层原样复用。
- 语法树文本必须与 Java 参考实现（`原生\前端` 的 `语法分析器` / `语法树打印器`）逐字节一致；
  同时与 `原生\测试\语法树快照` 的 35 份黄金快照逐字节一致。

### 2. 参考口径是新增的 `原生 语法` 子命令

固定输出格式（字段用 `\` 转义 `\`、`|`、换行、回车、制表）：

```
文件|<名称>
诊断|<错误|提示>|<码>|<行>|<列>|<长度>|<消息>|<建议>
树|<缩进>|<文本>
汇总|<文件数>|<解析成功数>|<诊断数>
```

- Java 侧在 `原生\前端\前端主程序.java` 新增 `语法` 子命令：只做词法诊断，不做
  CJK001 粘连与 CJK101–105 新手提示；词法有错时跳过解析，只输出诊断。
- 自举侧同格式输出，`原生\测试\对拍语法.ps1` 只保留 `文件| / 诊断| / 树| / 汇总|` 行比对。
- 两个新命令退出码恒 0：它们输出数据，不是构建结果。

### 3. 节点模型对齐 `语法树.java`，不复用 Java 类型

自举侧用中文 Java 的普通类 + 公开字段 + 构造器重建节点，打印器按参考实现的
缩进规则（两空格一级 + `\n`）逐行输出；节点类名可以与参考实现不同，但
打印文本必须相同。

### 4. 二期不做

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 语义分析 / MIR 自举 | 不做 | 依赖名称解析、类型检查与多文件语义 |
| 自举编译器编译自身 | 不做 | 仍无引导链，二期产物只做前端对拍 |
| CJK001 / CJK101–105 进 `语法` | 不做 | 不属于纯语法层，仍由 `原生 检查` 负责 |
| 替换生产路径的 Java 前端 | 不做 | 参考实现继续作为对拍基准 |

## 备选方案与取舍

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| 新开一个语法自举文件 | 未采纳 | 会复制词法层，破坏单一自举源 |
| 只比 AST 快照，不做行文本对拍 | 未采纳 | 覆盖不到诊断的行列与消息 |
| 用参考实现的节点类型做中间层 | 未采纳 | 自举源码不能依赖 JDK 侧类型 |
| 二期直接做到语义层 | 未采纳 | 范围与风险不可控 |

## 影响

- `原生\自举\分词器.java` → `原生\自举\自举前端.java`；`对拍分词.ps1` 与驱动路径同步。
- `原生 语法` 参考子命令；`原生\测试\对拍语法.ps1`；`原生 自举` 串联一期与二期。
- `校验.ps1` 新增 8.7 语法自举断言；ADR 计数 11 → 12。
- 修复自举源码中 `取().原文()` / `期望名称().原文()` 这类「带副作用调用作接收者」
  的写法：原生后端会重复求值接收者，改为先取到局部变量再访问。
- 修复运行时保守 GC 的根扫描上界：改用线程栈顶（TEB.StackBase）。原先记录启动时的
  栈底，clang -O2 把入口调用链内联进 `main` 后，活跃局部落在记录点之上被漏扫，
  自举前端 `分词` 扫教程目录时首次回收即崩溃；`cjk_gc_init` 随之删除。
- 词表仍是唯一数据源：自举只读 `工具\cjc\*.txt`，不复制。

## 验收

1. `自举前端.exe 语法 <根> 教程` 与 `cjc.ps1 原生 语法 教程` 逐字节一致（35 课，71 行，`汇总|35|35|0`）；
2. `自举前端.exe 快照` 产出的 35 份 `.ast.txt` 与 `原生\测试\语法树快照` 逐字节一致；
3. 4 条语法反例（缺 `;`、缺 `}`、非法表达式、缺 `)`）的行、列、消息、建议两侧一致；
4. 一期 `对拍分词.ps1` 仍为 4/4，不回归；
5. `.\工具\发布\校验.ps1 -含原生` 退出码 0。
