# ADR-011：M8 自举一期范围（词法层）

- 状态：已采纳
- 日期：2026-11-13
- 关联：路线图第 7 节 M8、ADR-003（前端与词表桥接）、ADR-006（运行时与对象模型）、ADR-008（测试与对拍）、ADR-010（明确「自举不做」）

## 背景

ADR-010 把「自举」列为 M7 不做项，理由是当时原生前端只覆盖单文件语义，
且自举需要前端自身的语义与后端能力稳定。M7 交付后（新前端、增量编译、
双后端 35 课对拍全绿），路线图第 10 节的「不先做自举」前提已不再成立。

自举的完整目标是「用中文 Java 重写编译器并编译自身」，但直接全量自举会同时
撞上三个未解决项：多文件语义、正则 / `Character` / `Files` 等 JDK API 缺失、
以及引导链（哪一版编译器编译哪一版源码）。因此一期只取**词法层**，
用最小闭环验证「中文 Java 能写出编译器的一部分，并由原生后端产出一个可执行文件」。

## 决策

### 1. 一期范围 = 词法自举

- 用中文 Java 重写三件事：4 份词表读取、词法分析、CJK001 / CJK002 / CJK106 诊断。
- 源码放 `原生\自举\分词器.java`，经 `cjc.ps1 原生 编译` 产出 `构建\自举\分词器.exe`。
- Token 流与诊断必须与 Java 参考实现（`原生\前端` 的 `词法分析器` / `词表`）逐字节一致。
- CJK101–105（新手易错提示）不在一期：它们依赖跨 Token 模式匹配，不属于纯词法层。

### 2. 验收物是「分词」子命令的对拍输出

固定输出格式（字段用 `\` 转义 `\`、`|`、换行、回车、制表）：

```
文件|<名称>
标记|<类别>|<行>|<列>|<原文>|<规范>
诊断|<错误|提示>|<码>|<行>|<列>|<长度>|<消息>|<建议>
汇总|<文件数>|<标记数>|<错误数>|<提示数>
```

- Java 侧在 `原生\前端\前端主程序.java` 新增 `分词` 子命令，作为参考实现。
- 自举侧同一格式输出，`原生\测试\对拍分词.ps1` 只保留两侧的
  `文件| / 标记| / 诊断| / 汇总|` 行做文本比对。
- 分词命令退出码恒 0：它输出的是数据，不是构建结果。

### 3. 只用原生后端已支持的 API，不扩编译器

自举源码遵守当前能力边界，不为了让自举通过而临时扩编译器：

| 缺口 | 替代写法 |
| --- | --- |
| 正则 / `Pattern` | 手写扫描 `拆行` / `切分词` / `是英文组名` |
| `Character.*` 全量 Unicode | 显式码点区间（空白、数字、字母、标识符） |
| `String.indexOf` / 单参 `substring` | `取子串(起, 止)` + 手写 `找字符` |
| `Files.readAllLines` 递归 | `文件助手.读所有行` / `读文本` / `列举`（单层） |
| `List.sort` | 插入排序 `排序文本` / `按长度排序` |

若后续确需扩编译器，另立 ADR，并先补最小探测程序验证，而不是在自举里夹带。

### 4. 一期不做

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 语法 / 语义自举 | 不做 | 依赖多文件语义与 JDK API，范围外 |
| 自举编译器编译自身 | 不做 | 一期只有一个可执行文件，没有引导链 |
| CJK101–105 | 不做 | 不是纯词法层 |
| 替换 Java 参考实现 | 不做 | 参考实现继续作为对拍基准与生产路径 |

## 备选方案与取舍

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| 直接全量自举 | 未采纳 | 语义层与 API 缺口同时爆发，无法定位问题 |
| 只自举词表读取 | 未采纳 | 不覆盖 Token 流，验证价值不足 |
| 用 Java 写自举但不产 exe | 未采纳 | 无法证明「中文 Java 能写编译器」 |
| 为自举扩编译器 API | 未采纳一期 | 会把自举 bug 与编译器 bug 混在一起 |

## 影响

- 新增 `原生\自举\`（自举源码）与 `原生\测试\对拍分词.ps1`；
  `原生\驱动.ps1` 新增 `分词` / `自举` 子命令。
- `cjk_set_args` 改用宽字符命令行，修复中文 argv（此前中文路径参数乱码）；
  链接补 `-lshell32`。
- `字符串.比较` 的实例形式在两个后端补齐（此前只支持静态形式）。
- `校验.ps1` 新增 8.6 自举对拍断言；ADR 计数 10 → 11。
- 词表仍是唯一数据源：自举只读 `工具\cjc\*.txt`，不复制。

## 验收

1. `分词器.exe 词表 <根>` 与 `cjc.ps1 原生 词表` 计数一致（56 / 121 / 34 / 50 / 52·3·56·10 / 65）；
2. `分词器.exe 分词 <根> 教程` 与 `cjc.ps1 原生 分词 教程` 逐字节一致（35 课，4934 行，0 差异）；
3. 3 条词法反例 CJK001 / CJK002 / CJK106 两侧输出一致且全部命中；
4. 中文路径（argv 与文件名）在自举 exe 中正常；
5. `.\工具\发布\校验.ps1 -含原生` 退出码 0。
