# ADR-010：M7 工具链与生态范围

- 状态：已采纳
- 日期：2026-11-12
- 关联：路线图第 7 节、M6（LLVM 后端）、ADR-005（C 后端与行号）、ADR-008（测试与对拍）

## 背景

M6 交付 LLVM 后端后，路线图第 7 节把 M7 定义为「工具链与生态」，列入增量编译、
包管理、LSP（补全/诊断）、交叉编译、可选自举，验收口径为：

1. `cjc.ps1 新建 项目` 后一条命令产出 exe；
2. VSCode 诊断来自新前端。

现状缺口：`新建 项目` 只生成 Maven JVM 工程；原生前端不支持 `包`；
VSCode 扩展直接调用旧的 `Cjc.java` 文本诊断；`原生 编译` 每次重编运行时。

## 决策

### 1. `新建 项目` 改为原生优先

- 生成 `构建.ps1`（调用仓库 `cjc.ps1 原生 编译` 产出 `target\应用.exe`），
  同时保留 `pom.xml` 的 JVM 路径。
- 工程源码保留 `包 演示.应用;`；原生前端在顶层消费 `包` 声明（不建 AST 节点），
  保证 AST 快照与既有后端零变化。
- 一条命令的验收物是 `构建.ps1`，不要求用户记两条命令。

### 2. 编辑器集成采用「新前端 + JSON 诊断」，不做完整 LSP

- `原生\前端` 新增 `诊断 --json`：逐行 JSON，字段固定为
  `码 / 行 / 列 / 长度 / 消息 / 建议 / 错误`，诊断是数据，退出码 0。
- `extension.js` 默认走新前端，保留 `cjc.diagnosticSource = "兼容"` 回退；
  新前端不可用时自动回退并提示一次。
- 补全数据由 `同步词表.ps1` 从词表生成（类型别名 / 方法糖 / 标准库类名），
  不再手写第二份。
- 不实现 stdio LSP 服务端：当前需求是诊断与补全，进程级调用已满足，
  引入 LSP 协议栈会显著扩大 M7 范围且没有新的用户价值。

### 3. 增量编译采用内容哈希对象缓存

- 运行时 `.c` 与模块 C/IR 均按内容 SHA256 缓存 `.o`，链接复用缓存对象。
- 状态文件记录 `源哈希 / 运行时哈希 / 工具链哈希 / 输出`；全部命中且 exe 存在时
  直接跳过。工具链哈希覆盖驱动、前端、中间表示与后端源码，改编译器必然失效。
- 旗标固定为既有 `-O2 -std=c11 -fwrapv -fno-strict-aliasing -static`，避免 ABI 漂移。
- 保留 `-无缓存` 作对照；缓存异常一律重编，不报错退出。

### 4. 包管理、交叉编译、自举本期不做

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 包管理 | 不做 | 原生前端只做单文件语义；远程依赖解析会引入版本求解与网络，收益不足 |
| 交叉编译 | 不做 | 运行时依赖 `ws2_32` / `winhttp` 与 Windows 控制台；一期只承诺 PE |
| 自举 | 不做（M8 已由 ADR-011 启动词法层） | 路线图第 10 节已明确「不先做自举」；当前应优先稳定语义与工具链 |

三者如需启动，另立 ADR，并先解决多文件语义与平台抽象。

> 2026-11-13 追补：M8 已按 [ADR-011](ADR-011-自举一期范围.md) 启动自举一期，
> 范围仅限词法层；本条其余约束（包管理、交叉编译）不变。

## 备选方案与取舍

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| 另加 `新建 原生项目` | 未采纳 | 验收口径明确指向 `新建 项目`，两套模板会增加选择成本 |
| 完整 LSP 服务端 | 未采纳 | 工作量大；诊断/补全用进程调用即可覆盖当前需求 |
| 增量编译只缓存运行时 | 未采纳 | 模块 C 编译同样是主要耗时，缓存模块 `.o` 收益更明显 |
| 交叉编译「先出 ELF」 | 未采纳 | 运行时的 Windows API 依赖未抽象，产出的 ELF 不可运行 |

## 影响

- 35 课对拍、AST/MIR 快照、DWARF 与基准均不得变化；`校验.ps1` 新增 M7 断言。
- `构建\原生\缓存\` 成为构建产物目录，不提交；缓存可随时删除。
- VSCode 扩展新增配置项，旧链路保留至少一个版本。

## 验收

1. `新建 项目` → `.\构建.ps1` → `target\应用.exe` 可运行；
2. `原生 诊断 --json` 字段齐全，CJK001 / CJK106 命中，退出码 0；
3. 第二次构建输出「增量：…跳过」，`-无缓存` 产物输出一致；
4. VSCode 扩展默认调用新前端，补全数据计数 34 / 52 / 3 / 56 / 10；
5. `.\工具\发布\校验.ps1 -含原生` 退出码 0。
