# ADR-017：M13 范围（平台抽象层 + 多文件模块，地基双雄）

- 状态：Accepted（已完成，2026-11-20；全量校验退出码 0）
- 日期：2026-11-20
- 关联：路线图第 7/14 节、M12 spec:32、ADR-001、ADR-010:47-55、用户 2026-11-20 方向决策

## 背景

M0–M12 全部完成并推送。路线图正文第 7 节只到 M12，M13 没有正式章节；M13/M14/M15 的编号只出现在 M12 spec:32（"不承诺 Linux ELF（M13）/ 多文件模块（M15）/ 包管理（M14）"）与 `.trae/...M11 实施计划` 第 7 节。ADR-010:55 明确：交叉编译与包管理启动前，须先解决平台抽象与多文件语义。

逐行核查现状后，两个前置依赖的工程量均被低估：
- 运行时 `文件.c`、`标准库.c` 全裸露 Win32/WinHTTP，`gc.c` 裸 `windows.h` + TEB 扫栈；平台耦合集中在少数文件但改造面广。
- 前端每文件独立 new 语义分析器（`前端主程序.java:657`），`类表` 是实例字段（:166），跨文件类型完全不可见；MIR/后端/驱动全按单文件设计。

用户 2026-11-20 决策：把两块地基合并为 M13 一起做，先方案后代码。

## 决策

### 1. 里程碑编号重排

| 旧编号 | 内容 | 新编号 / 处置 |
| --- | --- | --- |
| — | 平台抽象层 + 多文件模块 | **M13（本 ADR）** |
| M13 | Linux ELF 交叉编译 | M14（依赖 M13 平台抽象 + 交叉工具链） |
| M14 | 包管理 | M15（依赖 M13 多文件语义） |
| M15 | 多文件模块 | 并入 M13 |

### 2. 平台抽象层：行为保持重构 + 可插拔后端

- 新建 `cjk_platform.h` 收口六类平台接口，以 `值.c:373-398` 现有 `#ifdef/#else` 为样板。
- **Windows 后端逐字节复用现有实现**：抽象化是"搬运 + 加接口"，不是重写；Windows 行为是唯一硬验收口径。
- Linux 后端首轮目标为**可编译骨架**：类型/函数声明齐备，网络与文件 IO 做可桩化隔离并返回明确中文诊断，不追求跑通对拍。
- 本机**不产、不验收可运行 ELF**：`C:\msys64` 无 `x86_64-linux-gnu` sysroot/libc/crt1.o，WSL 被安全策略禁用。可运行性作为 M14 硬门槛，M13 只归档 `-fsyntax-only` 缺失系统头清单。

### 3. 多文件模块：两阶段共享类表 + 模块编译单元

- `包` 从"只消费标记"升级为 AST 节点；`编译单元` 增包字段，打印器无包时零新增行以保快照。
- 语义分析提供模块入口：pass1 跨文件注册类名/继承到共享类表（内建类只注册一次），pass2 逐文件分析方法体，合并为单个 MIR 程序，显式指定唯一 `<入口>`。
- 导入首轮只做"目标类是否在模块内"的校验，`java.*` 忽略；模块成员资格由驱动传入的文件列表决定，不实现 classpath 推导。
- C/LLVM 符号编码 `编码()`（简单类名 → 十六进制）**不改**：MVP 用"模块内简单类名唯一性诊断"规避冲突，改编码会连锁破坏 DWARF、快照与自举不动点。
- 自举前端（`自举前端.java`）**不纳入**本里程碑：不动点验证依赖参考端与自举端逐字节一致，多文件自举需另立 ADR 并同步重生成 `自举前端.mir.txt`。

## 理由

1. **依赖顺序纠正**：ELF 与包管理都建立在两块地基上，先做地基符合 ADR-010 自身的约束，避免在缺失抽象时硬推编号。
2. **风险可控**：两块地基都可在本机用"行为零回退 + 静态检查"验收，不依赖本机不具备的 Linux 运行环境；Windows 后端复用现有代码把回归风险压到最低。
3. **保护既有资产**：35 课对拍、105 份快照、自举不动点、DWARF 与基准都是 12 个里程碑积累的对拍基准，本方案通过"无包零新增行""不改编码""不改自举前端"三条硬约束锁定它们。

## 替代方案

| 方案 | 不采用的原因 |
| --- | --- |
| 按旧编号先做 M13 ELF | 本机无交叉工具链与运行环境，只能产 ELF 结构无法运行对拍；且运行时未抽象，根基不稳 |
| 先做包管理 | 依赖跨文件语义，前置未就绪 |
| 一次把 Linux ELF 做成可运行 | 需引入 sysroot/WSL（本机受限），范围与风险远超单个里程碑 |
| 改 C/LLVM 符号编码支持同名类 | 连锁破坏 DWARF、三类快照与自举不动点，收益不抵成本 |
| 多文件自举一起做 | 不动点基线需重生成，M8–M11 断言连锁改动，另立 ADR 更稳妥 |
