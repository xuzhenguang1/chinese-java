# ADR-013：M9 语义自举范围（名称解析与类型检查）

- 状态：已采纳
- 日期：2026-11-15
- 关联：路线图第 7 节 M9、ADR-008（测试与对拍）、ADR-012（自举二期范围）

## 背景

三期（ADR-012）已验证词法层与语法层可以自举。语义层依赖名称解析、类型检查
与大量 JDK 类型，风险高于前两层；但它是「中文 Java 能写编译器」的下一道门槛。

为把「自举 bug」与「参考实现 bug」分开，语义自举沿用前两期的做法：新增一个
只输出数据的参考子命令，逐字节对拍；区别是语义规则面大，必须显式圈定口径。

## 决策

### 1. 三期范围 = 语义检查自举，不产出 MIR

- 在 `原生\自举\自举前端.java` 内追加语义层：名称解析（类表、字段表、方法表、
  构造器表、作用域与局部变量）与类型检查（可赋值、子类型、方法/构造器匹配、
  返回值、条件、抛出/捕获、数组与三目）。
- 不做 MIR 降级，不打印 MIR，不碰解释器与 C/LLVM 后端。
- 不替换生产路径的 Java 语义分析器；参考实现继续作为对拍基准。

### 2. 参考口径是新增的 `原生 语义` 子命令

固定输出格式（单行字段用 `|` 分隔）：

```
类|<全名>|<父类或 ->|<接口数>|<字段数>|<方法数>
字段|<类全名>|<名>|<类型文本>|<静态?真/假>|<只读?真/假>
方法|<类全名>|<名>|<参数类型1,参数类型2>|<返回类型>|<静态?真/假>|<抽象?真/假>
诊断|<行>|<列>|<码>|<消息>
汇总|<文件数>|<类数>|<方法数>|<诊断数>
```

- 类行、字段行、方法行各自按整行字符串自然排序；诊断按文件与插入顺序。
- 任一文件词法或语法出错时，只输出 `汇总|0|0|0|0` 并立即返回（与前两层一致）。
- 语义词法错误码统一为 `语义`；参考实现捕获首个 `语义失败`，只产生 1 条诊断
  （行、列均为 0）；自举侧同样首错即停。
- 两个新命令退出码恒 0：它们输出数据，不是构建结果。

### 3. 类型模型：用户类严格，内置与泛型宽松

自举侧类型只保留 5 种：基本、数组、类、空、错误。

| 种类 | 用途 | 检查策略 |
| --- | --- | --- |
| 基本 | 整数/长整数/短整数/字节/浮点/双浮点/字符/布尔/无/文本 | 数值秩提升、同型、`文本` 与 `字符串` 归一 |
| 数组 | `T[]` | 元素类型可赋值 |
| 类 | 用户类、内建异常、包装类、内置容器 | 用户类按基类与接口做子类型判定 |
| 空 | `空` | 可赋给任何引用类型 |
| 错误 | 内置库、标准库、泛型参数、λ、方法引用、数组初始化 | 可赋值与运算判断一律放行 |

`错误` 类型是口径的关键：教程 35 课用到了 `清单` / `键值表` / `流` / `可选值` /
包装类 / 标准库静态类，参考实现有完整的 Java 类型映射，自举侧不重建这些类型，
只保证不误报。泛型参数（如 `盒子<T>` 中的 `T`）同样映射为 `错误`。

### 4. 三期不做

| 项 | 决定 | 理由 |
| --- | --- | --- |
| MIR 降级与打印 | 不做 | 后端与运行时不属于前端自举 |
| 多文件语义 | 不做 | 与参考一致：逐文件独立分析 |
| 泛型实例化与通配符推断 | 不做 | 泛型参数统一按 `错误` 放行 |
| λ 与方法引用类型推断 | 不做 | 按 `错误` 放行 |
| 字符串插值内部表达式检查 | 不做 | 参考实现已在语法层展开，自举侧同样处理 |
| `抽象类` 无实现校验、可达性/死代码 | 不做 | 参考实现也没有这些规则 |
| 替换生产路径的 Java 语义分析器 | 不做 | 参考实现继续作为对拍基准 |

### 5. 语义快照即黄金基准

- `原生\测试\语义快照\` 存 35 份 `<课名>.语义.txt`（LF、UTF-8 无 BOM），
  由 `.\cjc.ps1 原生 语义 教程` 逐文件生成，是自举侧的黄金基准。
- `原生\测试\反例语义\` 存 20 条单错用例与同名 `.语义.txt` 期望输出，
  覆盖重复声明、无方法体、接口构造器、缺初值、赋值/返回值/三目类型不符、
  找不到方法、条件非布尔、接口/抽象类实例化、抛出/捕获非异常、重复次数与
  数组下标类型、静态访问实例字段等规则。
- `原生\测试\对拍语义.ps1` 负责：教程 35 课逐字节对拍、35 份快照对拍、
  20 条反例（参考侧、自举侧、期望文件三方一致），输出「通过 3 / 共 3 项」。

## 备选方案与取舍

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| 新开语义自举文件 | 未采纳 | 会复制词法与语法层，破坏单一自举源 |
| 直接生成 MIR 再对拍 | 未采纳 | 范围翻倍，失败无法归因到语义层 |
| 重建 JDK 容器与泛型类型 | 未采纳 | 与「前端自举」目标无关，且极易误报 |
| 语义错误也带行列 | 未采纳 | 参考实现只给首个错误，行列固定为 0 |
| 多文件共享符号表 | 未采纳 | 与参考口径不一致，会制造假差异 |

## 影响

- `原生\前端\前端主程序.java` 新增 `语义` 参考子命令与速览打印；
- `原生\驱动.ps1` 新增 `语义` 子命令，`自举` 串联第三项；
- `原生\测试\语义快照\`、`原生\测试\反例语义\`、`原生\测试\对拍语义.ps1`；
- `校验.ps1` 新增 8.8 语义自举断言；ADR 计数 12 → 13；
- 自举源码运行在原生后端上，受「接收者重复求值」「局部变量必须初始化」
  「字符串字面量含 `{` 触发插值」等既有约束，写法上已规避。
