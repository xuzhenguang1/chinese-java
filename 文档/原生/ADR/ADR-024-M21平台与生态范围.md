# ADR-024：M21 平台与生态范围（Mach-O · registry/semver 含远程下载 · 完整 LSP）

- 状态：Accepted（2026-11-25 用户拍板 G7/G8/G9）
- 日期：2026-11-25
- 关联：后续路线计划书-M19至M22 §5、ADR-010（工具链与生态：明确推翻 §2「不做完整 LSP」与 §4「包管理不做」的剩余约束）、ADR-017（平台抽象）、ADR-018（Linux ELF：Mach-O 沿用其探针口径）、ADR-019（M15 包管理：明确推翻 D2「不做远程 registry/semver」）、ADR-022/023（符号与运行时地基，本里程碑冻结不动）
- 前置：M20 运行时二期已交付并推送（`9c1bccb`），全量校验 8.0–8.19 退出码 0，35 课 C/LLVM × PE/ELF 四路对拍 + 快照 + 自举不动点零回退，ADR 23 份

## 背景

M19（符号冲突根治）与 M20（运行时二期）交付后，符号编码、异常展开、泛型单态化、浮点根治四块地基冻结（ADR-022/023）。M21 是「外延扩展」里程碑：把平台从 PE/ELF 扩到第三个平台 macOS Mach-O，把包管理从「本地路径 + 精确版本」扩到「semver 范围 + 远程下载」，把编辑器集成从「JSON 诊断 + 补全」扩到完整 LSP。三块相互独立，按 ADR 分块推进、可分块交付。

2026-11-25 开工前对齐，用户拍板三项决策（计划书 §7.3 的 G7/G8/G9）：

- **G7（Mach-O）**：选「骨架 + CI 待跑」——本机 Windows 无 macOS runner，平台层/驱动/CI 全接线，本机只做可编译静态断言；macOS 真机 35 课 Mach-O 对拍标注「CI 实跑待环境」，不虚报全绿。
- **G8（registry）**：选「含远程下载」——**推翻 ADR-019 D2 与计划书原「不建远程 registry」非目标**。一期范围扩为本地 registry + semver 范围 + 远程 HTTP 下载 + 本地缓存；离线可复现通过「下载后缓存命中」保证，不依赖每次联网。
- **G9（LSP）**：选「四项全做」——**推翻 ADR-010 §2「不实现 stdio LSP 服务端」**。诊断/补全/悬停/定义跳转全部落地，VSCode 扩展改 LSP client 并保留 JSON 回退。

## 决策

### 1. 推进顺序与独立边界

三块按 **平台层（Mach-O）→ registry/semver → 完整 LSP** 顺序推进，每块独立提交、独立可回退：

- 平台层块（T1）与 registry 块（T2）都改到构建/清单链路，但互不依赖；LSP 块（T3）只新增 language server 与改 VSCode 扩展，不改编译器与运行时。
- 任一块受阻（尤其 Mach-O 的 CI 环境、远程下载的网络）**不阻塞其余块交付**，可按块分批推送，收口节 8.20 在最后一块落地后统一加。
- 硬门槛：每块落地后 35 课四路对拍、105 份快照、自举不动点 3/3、跨文件三方零回退；本里程碑**不碰**后端、运行时、MIR 文本、符号编码（ADR-022/023 冻结）。

### 2. Mach-O 平台（G7，骨架 + CI 待跑）

- **平台抽象层**：`原生/运行时/cjk_platform.h/.c` 新增 `CJK_PLATFORM_DARWIN` 分支——锁/原子/线程映射 pthread，路径用 POSIX，控制台与时钟按 Darwin 口径；不复制第二份实现，沿用 M13 六类接口（ADR-017）。
- **驱动**：`-平台` 扩 `darwin`，新增 target `x86_64-apple-darwin`、datalayout、sysroot 与 `-DCJK_PLATFORM_DARWIN` 配置桶；缓存哈希纳入平台名防 PE/ELF/Mach-O 串味。
- **LLVM 后端**：`LLVM平台配置.java` 新增 `darwin()` 工厂。**ABI 常量（datalayout、jmp_buf 元素、align、setjmp 签名、personality）一律按 ADR-018 口径用 clang 交叉编译探针实测，禁止照搬推测**；Mach-O 的 personality 预期为 `__gxx_personality_v0`（Itanium/DWARF 口径），实测为准。
- **交付形态（G7 定稿）**：本机（Windows）只能做「可编译静态断言 + 配置桶存在性断言」；CI 加 `macos-latest` job 接线 Mach-O 对拍脚本，但真机 35 课 C/LLVM Mach-O 对拍标注「CI 实跑待环境」，**不虚报全绿**。DWARF 检查从 `readelf` 口径扩到 `llvm-dwarfdump`（`CJK_DWARFDUMP` 可配置）。

### 3. registry/semver 含远程下载（G8）

- **清单 DSL 扩展**（沿用 ADR-019 中文 DSL，唯一格式）：`依赖` 指令的版本从「精确匹配」扩为 semver 范围（`^1.2` / `~1.2` / `1.x` / 精确 `1.2.0`）；版本比较按 semver 数值序，不按字符串序。保留 ADR-019 的中文 DSL、路径去重、查环、DFS 有序源文件列表、复用 M13 `分析模块` 等既有口径。
- **本地 registry 目录**：约定 `仓库/依赖库/<包名>/<版本>/依赖清单.txt`，作为离线可复现的权威来源；缓存命中时不访问网络。
- **远程 HTTP 下载器**：新增下载入口（registry 元数据 URL + 包归档 URL，可配置 base URL），下载产物落本地缓存目录并校验 SHA256；**必须有超时/重试/校验和失败路径**，无网或校验和不符给中文诊断「下载失败/校验和不符」、退出码 2，**禁止静默失败或用空值兜底**。
- **离线可复现**：下载后断网仍能解析闭包（缓存命中），反向用例强制验证「改版本范围必重编/重下」「缓存命中不联网」两条。
- **错误诊断扩展**：在 ADR-019 四类（循环/缺失/版本冲突/重复包）之上新增「范围无解」「下载失败/校验和不符」两类，均含路径/URL 上下文。
- **缓存击穿**：`驱动.ps1` 的 `取工具链哈希` 与状态 `依赖哈希` 纳入清单文本 + 已下载包的版本元数据哈希（ADR-019 §3 口径扩展）。
- **本机无稳定外网时**：远程下载用例标注「CI 实跑待环境」，本地 registry + 缓存用例兜底，不把网络不可达误判为功能失败。

### 4. 完整 LSP（G9，四项全做）

- 新建 language server（stdio LSP 服务端，Node/Java 均可，优先复用 `原生 诊断 --json` 与补全数据单一数据源），提供 **诊断 / 补全 / 悬停 / 定义跳转** 四项能力；不重复维护词表/方法糖/标准库清单。
- VSCode 扩展（`工具/vscode-中文java/extension.js`）改为 LSP client，保留原 JSON 诊断回退口径（`cjk.diagnosticSource = "兼容"`）：LSP 不可用自动降级，不回退既有诊断/补全行为。
- 按仓库规则重建 vsix（`npx --no-install @vscode/vsce package`），版本随 `工具/版本.json` 同步（ADR-010 影响节口径）。
- 不替换 VSCode Java 扩展的语言模式；不引入新语言语义，LSP 只是既有诊断/补全数据的协议化出口。

### 5. 不变项（冻结）

- 不改 C/LLVM 后端与运行时（M19–M21 冻结，M22 才换前端来源）。
- 不改 MIR 文本、对象头/数组布局、UTF-16 字符串、M19 符号编码与别名。
- 不改 35 课源文件、105 份快照、自举不动点与四路对拍基线。
- 不做跨架构矩阵（仅 x86_64；macOS 视 runner 架构 arm64 另议）；不做远程 HTTP registry 的服务端托管（本 ADR 的「远程下载」仅指消费远端包归档，自建 registry 服务不在范围）。

## 回滚预案

- 三块各自独立提交：阶段 0（ADR）→ 阶段 1（平台层）→ 阶段 2（registry）→ 阶段 3（LSP）→ 阶段 4（校验 + 文档）。任一块失败 `git revert` 该阶段提交，前序块基线干净。
- Mach-O 若 CI macos job 仍无法真机验证：保留骨架 + 静态断言，对拍报告写明「CI 实跑待环境」，不回退平台层接线，也不虚报全绿。
- 远程下载若引入不稳定网络失败：保留本地 registry + 缓存路径为默认离线闭环，远程下载失败给中文诊断而非静默；必要时可临时禁用远程入口（保留代码与诊断），不影响本地解析。
- LSP 若改造影响现有 VSCode 用户：JSON 回退路径保留，LSP 失败自动降级；vsix 可回退上一版本。
- G8/G9 推翻的 ADR-010/019 旧口径在本 ADR 标记，若整块回退须同步恢复旧 ADR 口径，避免文档与实现漂移。

## 验收

1. Mach-O：平台层/驱动/CI 接线齐备，本机可编译静态断言通过；macOS 真机 35 课 C/LLVM 对拍标注「CI 实跑待环境」（G7，不虚报全绿）；ABI 常量来自探针实测。
2. registry（G8）：semver 范围解析正确、本地 registry 离线可复现、远程下载后断网仍可复现、缓存反向用例通过、下载失败/校验和不符/范围无解命中中文诊断退出码 2。
3. LSP（G9）：诊断/补全/悬停/跳转四项可用，VSCode 扩展实跑通过，JSON 回退不回退，vsix 已重建。
4. `.\工具\发布\校验.ps1 -含原生` 新增 8.20 后退出码 0，ADR 总数 24；自举不动点 3/3、35 课四路对拍、105 份快照零回退。
