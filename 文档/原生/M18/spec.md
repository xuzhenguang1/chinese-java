## 1. 目标 / 非目标

**目标**：解除自举"逐文件独立分析、不共享符号表"的限制，让自举前端具备跨文件两阶段分析能力，建立跨文件不动点；单文件路径完全不动，35 课快照与 175 组单文件不动点零回退。

1. **中文版两阶段分析器**：在自举前端单文件内实现 pass1 跨文件注册声明 + pass1 尾校验 + pass2 一次分析全部方法体，对齐参考 `语义分析器.分析模块`（`语义分析器.java:222-245`）。
2. **跨文件命令**：新增自举侧 `语义模块` / `中间模块`，**两种输入都支持**——显式源文件列表（入口优先，主对拍口径）与 `依赖清单.txt` 路径（F1-C）；两条路径必须解析出同一组有序源文件。
3. **专用多文件样例**：按已拍板 D4 另建 `原生/测试/自举多文件样例/`，6–8 文件，覆盖 pass1 注册、pass2 方法体、入口唯一校验三条路径。
4. **跨文件不动点**：A/B 两实现 + 参考三方输出逐字节一致；单文件 175 组与 35 课快照保持零回退。

**非目标**：
- 不改参考实现 `语义分析器.java`（已支持跨文件）、不改 `编码()`、不改 JVM 后端。
- 不改单文件 `语义` / `中间` 命令的任何输出字节与 `// 文件名` 分段口径。
- 不把示例工程 10 文件当作不动点样本（D4 已拍板另建专用样例）。
- 不实现 MIR 文本 → 程序对象的解析入口（M11 已确认参考 C 后端无此能力，继续用等价不动点口径）。

## 4. 核心设计

### 4.1 中文版两阶段分析器（自举前端.java 内）

对齐参考 `分析模块` 的四个阶段，全部复用 `语义检查器` 现有字段与方法，不复制第二份语义实现：

1. **pass1 注册**：`注册内建类()` **只调用一次**；遍历全部 `编译单元节点`，逐单元 `收集类(声明, 空)`（复用 `:3914 收集` 的声明收集部分，但**不**触发 `分析全部`）。脚本兜底只在单文件回退路径保留，模块路径不做（对齐参考 `:215-216`）。
2. **pass1 尾校验**：按参考 `:248-...` 的口径实现三个中文诊断——导入未找到（模块内类放行、`java`/`javax` 忽略）、引用类型不可解析、入口不唯一。顺序固定为 导入 → 引用类型 → 入口。
3. **pass2 分析**：在全部类已注册的前提下调用一次 `分析全部()`（`:4376`），使跨文件类引用在方法体分析中可解析。
4. **产出**：调用 `生成程序()`（`:5795`）得到单个 `中间节点` 程序，一次打印；模块语义命令输出与参考 `语义模块` 同格式文本（类/字段/方法/诊断/汇总行），口径在 T3 用专用样例逐字节锁定。

**单文件回退**：`语义` / `中间` 命令检测到恰好 1 个源文件时，**原样执行现有循环**（包括每文件新建检查器、`// 文件名` 判定、汇总行），输出与基线逐字节一致；模块逻辑只在新命令或 ≥2 文件时进入。

### 4.2 跨文件命令与输入契约（F1-C：两者都支持）

```
# 形式一：显式源文件列表（主对拍口径）
自举前端 语义模块 <根> <入口源> <其他源...>
自举前端 中间模块 <根> <入口源> <其他源...>

# 形式二：清单路径（自举侧直接解析）
自举前端 语义模块 <根> -清单 <依赖清单.txt>
自举前端 中间模块 <根> -清单 <依赖清单.txt>
```

- 显式列表的参数顺序与参考 `前端主程序 编译模块 <根> <输出> <入口> <其他源...>` 一致（入口在第一个）。
- 清单路径由自举 exe 直接解析：`依赖清单.java` 的五行 DSL（`包名`/`版本`/`入口`/`源目录`/`依赖`）规则在自举单文件内用已有 `拆行` + 自写 `切空白词` 实现（`切分词` 按逗号切分不适用），不引正则；源文件按文件名去重以避免 `源目录 .` 的路径文本差异；一期只做本地路径 + 精确版本、不做远程与范围求解（与 M15 同边界）。
- **一致性硬断言**：同一份样例，形式一与形式二必须产出完全相同的有序源文件列表（入口相同、其余按路径排序），并且语义/MIR 输出逐字节一致；由 `对拍自举模块.ps1` 的双输入对拍项锁定。
- 自举侧 `中间模块` 输出**单个** MIR 程序，不打印 `// 文件名` 分段前缀（因为合并为一个程序）；原 `中间` 命令多文件分段口径不变。

### 4.3 专用多文件样例（D4）

`原生/测试/自举多文件样例/`，6–8 文件，刻意小于示例工程 10 文件：

| 覆盖点 | 样例构造 | 必须命中的路径 |
| --- | --- | --- |
| pass1 跨文件注册 | A 文件声明基类/接口，B 文件引用 | `收集类` 在另一个单元的类上可见 |
| 跨文件继承 + 方法重写 | 子类在 B、父类在 A，方法体调 `父类.方法` | pass2 方法体分析解析跨文件符号 |
| 跨文件接口实现 | 接口在 A、实现在 C，入口经接口类型调用 | 接口实现链与子类型判定 |
| 包声明与导入 | 每文件 `包` + `导入`，含一个 `java.*` 导入 | 导入校验放行规则 |
| 入口唯一 | 仅入口文件含脚本语句/`<入口>` | 唯一入口校验（正例） |
| 负例（独立小目录） | 双入口 / 未找到导入 / 引用不存在类型 | 三条中文诊断与参考侧一致 |

### 4.4 不动点口径

- **单文件**：原脚本 2 项断言不动（自身 MIR `A==基线==B` + 175 组 A==B），基线按 F3-A 迁移后仍为这 2 项服务。
- **跨文件新增第 3 项**：A/B 两个自举 exe 对专用样例跑 `语义模块`/`中间模块`，输出逐字节一致；同时与参考侧 `语义模块`/`中间模块`（F2-A）逐字节一致；结果落 `构建/自举/跨文件不动点/`（不入库）。
- **A 的重编口径**：A 用**改造后的新前端**重新编译后再作为不动点起点（计划书 6.3），即 A 与 B 同源同参独立编译，避免历史 exe 与新增命令不兼容造成假失败；历史 exe 仅作为回归对照，不参与新断言。
- 不比较 exe 二进制哈希（链接时间戳不稳定），沿用 M11 等价不动点口径。

## 5. 任务分解概览

按 F4-B **一次到位**（不设中间提交点），内部仍分两阶段推进；详细清单见 `tasks.md`。

**硬门槛**：T0.1 基线未冻结不动 T1；单文件回退路径不通过不进阶段二；每改一处立刻跑 35 课对拍与 175 组不动点。

## 6. 验收口径

1. 单文件路径 35 课 AST/MIR/语义快照与 175 组不动点**逐字节零回退**；历史 MIR 基线只读对照存在。

4. 双输入一致性：显式文件列表与 `-清单` 清单路径对同一样例产出的源文件列表与语义/MIR 输出逐字节一致。
