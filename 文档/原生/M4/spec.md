## 1. 目标

- `是`（instanceof，含 `是 类型 变量` 模式绑定）、向下转型
- 枚举：常量、字段、构造器、`全部值()`、`值(文本)`
- `切换` 表达式与语句
- `尝试` / `捕获` / `兜底`（finally）、`抛出`、`声明抛出`
- 内建：`算术.平方根`、`整数.解析`、字符串 `是空` / `等于`、`异常.取消息`

## 2. 对象模型

沿用 ADR-006：

- 对象头 `{ cjk_class* cls }`；字段紧随其后，按 8 字节对齐。
- 每个类生成一个 C 结构体，字段按「祖先在前、本类在后」扁平排列，保证父类字段偏移在子类中不变。
- 每个类生成一个 `cjk_class` 描述符：`id`、`name`、`parent`、`methods[]`（虚方法槽）、`interfaces[]`。
- 方法槽在 C 生成阶段全局编号：同名同参数类型的实现共用一个槽；重写替换槽，继承复制槽。
- 接口按「只有方法的抽象类」处理，接口方法占用普通槽，不额外做 itable；`是` 与捕获沿 `parent` 链匹配。
- 静态字段生成 C 全局变量；静态方法生成普通 C 函数；类名限定调用直接静态绑定。
- 隐式根类 `对象`；所有类默认继承 `对象`。

## 3. 异常模型

- 运行时异常处理器栈：`setjmp` / `longjmp`。
- 生成代码中的 `尝试`：
  1. `setjmp` 正常路径压栈并执行尝试体；
  2. 异常路径取出当前异常并弹栈，按 `捕获` 顺序沿类继承链匹配；
  3. `兜底` 在正常与捕获路径后都执行；未匹配的异常在兜底后继续向外抛出。
- 内建异常类（不在源码中声明）：
  - `异常`（根，字段 `消息`，方法 `取消息()`）
  - `运行时异常` 继承 `异常`
  - `算术异常`、`空指针异常`、`数组越界异常`、`非法参数异常`、`数字格式异常` 继承 `运行时异常`
- 与 JVM 对齐的消息：
  - 整数除零与取余：`/ by zero`
  - 数组越界：`Index <下标> out of bounds for length <长度>`
  - 空指针：字符串长度为 null 时抛 `空指针异常`（消息为 null）
  - `抛出 新建 非法参数异常("…")`：消息即实参文本
- 未捕获异常：打印中文异常类名与消息、中文源文件与行号，退出码 1；不出现英文栈。

## 4. GC

- 本机未安装 Boehm GC（`C:\msys64\mingw64\include\gc.h` 不存在）。
- 在 `运行时\gc.c` 内实现保守标记-清除，保持 ADR-006 的接口边界，后续可替换为 Boehm：
  - 所有对象、字符串、数组、异常经 `cjk_gc_alloc` 分配；
  - 根：C 栈（当前栈指针到 `cjk_rt_init` 记录的栈底）、`setjmp` 保存的寄存器、显式登记的全局根（静态字段与枚举常量）；
  - 保守扫描，支持指向块内部的指针；
  - 分配量超过阈值时触发，回收后阈值翻倍。
- 压力用例：长循环创建对象与字符串不崩溃，进程内存不持续线性增长。

## 6. C 生成约定

- 类结构体：`typedef struct { cjk_class* cls; <字段...> } _cjkobj_<类名>;`
- 类描述符：`static cjk_class _cjkcls_<类名>;`
- 构造：`_cjknew_<类名>(...)` 分配、写类指针、初始化字段、调用父构造器或 `这(...)`、执行构造器体。
- 实例方法：`static <返回> _cjkf_<类名>_<方法>_<签名>(void* self, ...)`，首参为对象指针。
- 虚调用：`((<返回>(*)(void*, ...))((cjk_class*)obj->cls)->methods[<槽>])(obj, ...)`。
- `父.方法()`：直接调用父类实现。
- 字段访问：`((_cjkobj_<声明类>*)recv)->_f_<字段>`；解引用前插入空检查。
- `是`：`cjk_is_instance(obj, &_cjkcls_<目标类>)`；模式绑定降为「赋值给临时变量并判非空」。
- 枚举：类静态初始化函数创建常量对象；`全部值()` 返回引用数组；`值(文本)` 按常量名查找。
- 异常类由运行时提供描述符 `CJK_CLS_<异常名>`，C 生成器直接引用，不重复生成。
