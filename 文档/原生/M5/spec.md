# M5 标准库全量 + 集合与泛型（22–35 课）

- 状态：进行中
- 日期：2026-11-10
- 关联：路线图第 8 节 M5；ADR-006（运行时与对象模型）；ADR-007（语义兼容与差异白名单）；ADR-008（测试与对拍策略）

## 1. 目标

在 M4 的对象模型与异常之上补齐泛型、集合、流、λ、记录、密封类与标准库，使教程 22–35 在原生后端的 stdout、退出码与 JVM 后端逐字节一致，并实现 10 个标准库类的全部公开方法。

- 集合：`清单`/`数组清单`、`键值表`/`链式键值表`、`集`/`散列集`/`哈希表`
- 字符串全量方法与 `文本构建器`
- 泛型类、泛型方法、通配上界（擦除后按 `对象`）
- λ、方法引用、`比较器`、`流`、`收集器`、`可选值`
- 记录、`密封`/`许可`/`非密封`
- 成员内部类与静态嵌套类
- `入口` 自动提供 `参数`、`文件路径`/`文件助手`/`文件`
- `切换` 表达式块分支中的 `产出`
- 标准库 10 类：`输出`/`文本`/`数值`/`时间`/`文件`/`集合工具`/`并发`/`网络`/`日志`/`数据`

不在 M5 范围：反射、注解处理、泛型特化（类型参数擦除为 `对象`）、协程、非 Windows 平台的网络一期。

## 2. 类型系统

- `类型` 增加泛型实参：`类类型(名, 实参列表)`；`同型` 先比原始类名，再比实参。
- 内置类型族（隐式类，不生成 MIR 类定义）：
  - `清单<T>`、`键值表<K,V>`、`集<T>`
  - `文本构建器`、`文件路径`、`可选值<T>`、`流<T>`、`比较器<T>`
  - 包装类：`整数包装`/`长整数包装`/`双浮点包装`/`布尔包装`/`字符包装`
  - 标准库：`输出`/`文本`/`数值`/`时间`/`文件`/`集合工具`/`并发`/`网络`/`日志`/`数据`
  - 日期：`本地日期`、`本地日期时间`；`日志记录器`、`响应`、`线程池`、`未来`
  - 异常补充：`输入输出异常`（继承 `异常`）
- 泛型擦除：类型参数一律按 `对象` 处理；泛型集合保留静态元素类型，用于返回值、λ 形参推断与增强 for 检查。
- 装箱/拆箱：基本类型与包装类在赋值、集合存取、`整数.值(...)` 处按需转换。

## 3. 值模型与运行时

- 新增 `cjk_value { int32_t kind; union { int64_t i; double d; void* p; } }`：
  `空/整数/长整数/双浮点/布尔/字符/引用`。
- 集合元素、Map 键值、Stream 元素、Optional 值、Future 结果统一用 `cjk_value` 存取；
  静态类型到 `cjk_value` 的转换由 C 生成器按类型插入。
- 集合对象首字段为 `cjk_class*`，沿用对象模型与 GC：
  - `cjk_list`：动态数组 `len/cap/cjk_value*`
  - `cjk_map`：插入有序哈希表（键值对数组 + 索引）
  - `cjk_set`：去重列表
  - `cjk_builder`、`cjk_optional`、`cjk_stream`、`cjk_path`、`cjk_date`、`cjk_logger`、`cjk_pool`、`cjk_future`
- 打印/`转文本` 统一走 `cjk_value_to_string`：基本类型直接格式化；引用类型调用类描述符的
  `to_string` 函数指针；未重写时输出 Java 默认 `类名@哈希`。
- 容器 `toString` 对齐 JDK：List `[a, b]`、Map `{k=v, k2=v2}`、Set `[a, b]`。
- 并发：Windows 线程（`_beginthreadex`）；工作线程进出时调用 `cjk_gc_enter_thread` / `cjk_gc_leave_thread`，多线程存活期间暂停自动回收。
- 网络：WinHTTP HTTPS GET，一期仅 Windows；失败抛 `输入输出异常`。
- 记录哈希码按 javac 生成公式（初值 0、每分量 `31 * 结果 + 哈希`）计算，字符串用 Java `String.hashCode`。

## 4. λ 与方法引用

- λ 降级为合成类 `__λ<N>`：捕获变量成为字段，构造器赋值，实例方法 `调用(形参...)` 承载方法体。
- 方法引用 `学生::总分` 合成 `__方法引用<N>`：`调用(学生)` 体内 `返回 参数.总分()`。
- `比较器.按整数(λ)` → 合成比较器类（字段 `键`，`比较` 返回整数差）；`.反序()` → 包装类交换实参。
- `整理(集合, 比较器)`、`流.过滤/变换/遍历`、`可选值.存在时` 由运行时按「对象 + 虚槽号」回调；
  槽号在 C 生成器全局编号。

## 5. 产出与切换表达式

- 新增 MIR `顺序表达式(类型, List<语句> 前奏, 表达式 结果)`：
  C 生成逗号表达式 `(语句..., 结果)`，解释器顺序执行。
- `切换表达式` 块分支以 `产出 值` 结尾时降级为「前奏语句 + 顺序表达式」；
  仅支持表达式语句/局部变量/产出，其他块形式给明确诊断。
- `切换语句` 保持 M4 行为。

## 6. 内部类与记录

- 嵌套类扁平命名 `外部$内部`；`类符号` 记录外层类表。
- 成员内部类增加隐藏字段 `__外部`，`新建 内部(...)` 自动传入当前 `这`；
  内部访问外部字段生成 `这.__外部.字段`。
- 静态嵌套类按普通类处理；`工具.常量.前缀` 通过外层类表解析。
- `记录 学生(字符串 姓名, 整数 年龄)` 在语义阶段生成：
  - 字段、规范构造器、访问器 `姓名()`/`年龄()`
  - `转文本`：`学生[姓名=小明, 年龄=18]`
  - `哈希码`：Java record 公式，字符串用 Java `String.hashCode`
  - `等于`：同类 + 各分量 `Objects.equals`
- `密封`/`许可`/`非密封`：许可列表仅记录，不做类型检查；`非密封 类` 按普通类处理。

## 7. 命令行参数与文件

- `入口` 自动定义 `参数`（`字符串[]`），初值为内建 `程序参数`；
  解释器从 `运行` 实参传入，C 入口把 `argc/argv` 转 UTF-8 字符串数组。
- `文件路径` 保存绝对路径字符串；`文件路径.取(段...)` 按平台拼接并规范化。
- `文件助手`/`文件` 的读写、建目录、存在、读所有行、列举、大小、删除均走 UTF-8；
  `读所有行` 忽略末尾空行；失败抛 `输入输出异常`。

## 8. 标准库 10 类

以 JVM 侧 `标准库/src/main/java/中文/标准库` 的公开签名为准，原生逐方法实现：

- `输出`：`打印`/`打印行`（0/1/多实参）、`错误`、`格式`（`%s`/`%d`/`%f`/`%%`/`%n`）
- `文本`：`是否为空`/`是否空白`/`去空白`（Unicode 空白）/`分割`（按字面量）/`重复`/`连接`
- `数值`：`转文本`/`是整数`/`随机整数(上限)`/`随机整数(下限, 上限)`（含两端）
- `时间`：`今天`/`此刻`/`时间戳`/`格式化`（数字模式，如 `yyyy-MM-dd`）/`相差天数`/`加天数`
- `文件`：`读文本`/`写文本`/`存在`/`建目录`/`列举`/`大小`/`删除`（不存在时静默成功，对齐 `deleteIfExists`）
- `集合工具`：`填充`
- `并发`：`固定线程池`/`单线程池`/`执行`/`提交`/`取结果`/`关闭`/`休眠`/`当前线程名`（λ 直接作为任务）
- `网络`：`取文本`/`取状态码`/`取`（`响应.状态码()`/`响应.正文()`）/`下载到`
- `日志`：`取`/`控制台`（同名全局单例）/`信息`/`警告`/`错误`/`调试`/`设置级别`
- `数据`：`转JSON`（紧凑/美化；null、字符串、字符、布尔、数字、清单、映射、一维数组）

### 8.1 与 JVM 的差异与诊断

- `文本.分割` 原生按字面量子串切分（`String.split` 的正则语义一期不做）；含正则元字符时行为不同，勿依赖。
- `日志.设置级别` 原生接受级别名文本（`"FINE"`/`"INFO"`/`"WARNING"`/`"SEVERE"`/`"OFF"`），JVM 侧为 `Level` 对象。
- `数据.转JSON` 不支持多维数组，编译期给「M5 暂不支持：数据.转JSON 的多维数组，请先转为清单」。
- `输出.格式` 仅支持 `%s`/`%d`/`%f`/`%%`/`%n`；其他转换符抛 `非法参数异常`，消息含该转换符。
- `网络` 一期仅 Windows（WinHTTP）；连接失败或响应异常抛 `输入输出异常`，正文按 UTF-8 解码。
- 对象默认哈希取指针相关值，与 JVM identity hash 不同；对拍只覆盖重写 `哈希码` 的类（如记录）。

无法对齐 JDK 的方法返回明确中文诊断，不允许链接错误或空值。
