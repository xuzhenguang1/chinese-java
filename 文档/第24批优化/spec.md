# 第24批优化规格：插值优先级修复与打印写法统一

## 1. 目标

学习者写字符串插值时，最自然的方式是 `"和：{甲 + 乙}"`。但这一写法此前会静默出错：展开成 `"" + 甲 + 乙`，Java 从左到右先把字符串与甲拼起来，结果变成 `"23"` 而不是 `5`。本批修掉这个静默错误，并把教程里仍是 `"前缀：" + 表达式` 的旧打印写法统一为多实参 `打印行` 或插值，让学习者只看到一套写法。

## 2. 发现的问题

| 编号 | 位置 | 问题 |
| --- | --- | --- |
| P1 | `Cjc.java` 字符串插值 | `{甲 + 乙}` 展开为 `"" + 甲 + 乙`，运算变成字符串拼接，输出 `23` 而非 `5`，且不报错 |
| P2 | 教程 8 个文件 | 仍用 `"标签：" + 表达式` 拼接打印，与主推的多实参 `打印行("标签：", 表达式)` 和插值写法不一致 |

## 3. 变更明细

### 3.1 插值运算符加括号

`appendInterpolationParts` 在展开表达式时，若表达式含**顶层**运算符就给整体加括号：

```java
String text = needsParens(value) ? "(" + value + ")" : value;
```

新增 `needsParens`：括号/方括号内的运算符不算；`+ - * / % & | ^ ! < > =` 出现在第 0 层即判定需要加括号。因此：

```java
整数 甲 = 2; 整数 乙 = 3;
打印行("和：{甲 + 乙}");   // 展开为 System.out.println("和：" + (甲 + 乙))
```
