# 第 30 批优化：漏导入标准库的诊断直达

## 1. 目标

学习者第一次用标准库（`输出`、`数值`、`文本` 等）时，最常忘写 `导入 中文.标准库.*;`。改前只会看到「找不到符号：变量「输出」」，不知道下一步该做什么；改后诊断直接说清是标准库类，并给出可照抄的导入写法。

## 2. 现状（改前实测）

`构建\第30批\未导入.java`：

```java
类 测试标准库 {
    入口 {
        输出.打印行("你好");
    }
}
```

`.\cjc.ps1 编译 构建\第30批\未导入.java -d 构建\第30批\输出` 输出：

```
错误：第3行 第9列  找不到符号：变量「输出」
    建议：确认变量已声明或已赋值；若来自其他类，检查是否用「导入」引入。
```

问题：

1. 把标准库类当成「变量」，定性不准。
2. 建议只说“检查是否用导入”，没有给出具体写法，初学者仍要翻文档。
