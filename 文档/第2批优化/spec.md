## 2.1 语法糖 `否则若`

问题：`否则 若 (` 已可用，但初学者常写 `否则若 (` / `否则若(`，会被当作标识符并触发 CJK001 粘连错误。

改动文件：`工具\cjc\Cjc.java`

1. 新增辅助方法（放在 `checkSticky` 附近）：

```java
/** 语法糖 `否则若`：紧跟 `(`，且位于语句开头或 `}` / `;` / `{` 之后。 */
static boolean isElseIfSugar(SourceFile sf, int idx)
```

判定条件：
- `tokens[idx]` 是 `KIND_IDENTIFIER` 且文本为 `否则若`；
- `tokens[idx + 1]` 的文本是 `(`（`prevText` 自动忽略空白）；
- `idx == 0` 或前一个 token 文本属于 `}`、`;`、`{`。

2. `checkSticky` 改为按下标遍历；命中 `isElseIfSugar` 时 `continue`，不再报 CJK001。

3. `translate()` 增加 `boolean[] renameElseIf`：
- 用 `isElseIfSugar` 标记；
- 在输出循环中、`t.kind == KIND_KEYWORD` 分支之前，把该 token 替换为 `else if`，并用 `pending` 登记 `{origStart, 原长度, genStart, 7}` 保证列号回映射。

4. 行为：`否则若 (` 与 `否则若(` 都转成 `else if (`；名为 `否则若` 的变量/方法（不满足上述上下文）不受影响。

## 2.2 CJK104：循环上界用 `<=` 且右侧是长度

改动文件：`工具\cjc\Cjc.java`

1. `checkBeginnerTraps` 增加 `count += checkLoopBound(sf);`。
2. 新增：

```java
/** CJK104：`for` / `当` 的条件里 `<= 集合.元素数()` / `<= 数组.长度` 会多走一轮。 */
static int checkLoopBound(SourceFile sf)
```

实现要点：
- 遍历 token，找 `KEYWORDS.get(text)` 为 `for` 或 `while` 的关键字，且下一个 token 是 `(`；
- 由 `(` 起按括号深度找到配对的 `)`；
- `for` 只检查头部第 2 段（顶层 `;` 分隔的第 1 与第 2 个分号之间）；`while` 检查整个括号内容；
- 在该区间内找相邻的 `<`、`=` 两个 token（`sf.original.startsWith("<=", 左 token.start)`）；
- 取 `=` 之后到区间末尾的原文 `trim()`，匹配正则 `^\S+(\.长度|\.元素数\(\))$` 才提示；
- 不匹配时静默（例如 `<= 3`、`<= 名单.长度 - 1`、带 `&&` 的复合条件）。
- 提示文案：
  - 问题：`循环条件「… <= 名单.长度」会多走一轮，取下标时最后一次越界。`
  - 建议：`把「<=」改成「<」（0 起始取下标）；确实要包含末尾时写「<= 名单.长度 - 1」。`
- 报告位置：`<` 所在列，代码 `CJK104`。

## 2.3 CJK105：整数除整数会截断小数

改动文件：`工具\cjc\Cjc.java`

1. 新增 `static Set<String> intVariables(SourceFile sf)`：
   - 与 `stringVariables` 同构，识别 `整数` / `长整数`（对应 `int` / `long`）以及英文 `int` / `long` 声明；
   - 跳过 `[` `]` 形式的数组声明。
2. 新增：

```java
/** CJK105：`/` 两侧都是整数（字面量或声明为整数/长整数的变量）。 */
static int checkIntegerDivision(SourceFile sf)
```

实现要点：
- 只认 `KIND_OTHER`、`text == null`、`original.charAt(start) == '/'` 的 token；`/=` 跳过；注释与字符串已在扫描阶段排除。
- 左/右操作数均为整数：整数变量，或整数字面量（`KIND_OTHER` 且以数字开头，且不含 `.`、`e`、`E`、`f`、`F`、`d`、`D`）。
- 提示文案：
  - 问题：`整数相除会丢弃小数部分：5 / 2 得 2，而不是 2.5。`
  - 建议：`需要小数结果时把其中一个操作数写成小数（5.0 / 2），或先转成双浮点：(双浮点) 被除数 / 除数。`
- 代码 `CJK105`，位置在 `/` 所在列。
3. 抑制机制（为满足「零误报」并为用户留出口）：
   - 新增 `static boolean trapSuppressed(SourceFile sf, Token token)`：该 token 所在行文本包含 `忽略提示` 时返回 true；
   - `reportTrap` 改为 `static boolean`：被抑制时直接 `return false`，否则打印并 `return true`；
   - 现有 CJK101–103 调用点改为 `if (reportTrap(...)) count++;`，新增 CJK104/105 同样处理。
4. `教程\第03课运算与字符串.java` 第 9 行是本课「整数除法」教学点，行尾补注释：
   `// 忽略提示 CJK105：本课专门演示整数除法`

## 2.5 运行时异常中文化复核
