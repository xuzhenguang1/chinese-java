# 第28批优化规格：`输出` 家族补齐与教程测试说明校准

## 1. 目标

第 25 批给 `输出.打印` / `输出.打印行` 加了多实参重载，但标准错误 `输出.错误` 仍是单参数，同一个“输出”家族出现两种写法。本批补齐 `输出.错误(Object...)`，并修正教程 9.1 仍写“十一组用例”、漏列 `输出` 的过期说明。

## 2. 发现的问题

| 编号 | 位置 | 问题 |
| --- | --- | --- |
| P1 | `标准库\输出.java` | `打印` / `打印行` 已支持多实参，`错误` 仍只收单个 `Object`，写错误信息又要拼字符串 |
| P2 | `教程\教程.md:382` | 仍写“十一组用例”，且未提第 25 批新增的输出测试；实际已是十二组 |
| P3 | `语言规范.md` / `速查表.md` | 多实参说明只写了 `打印` / `打印行`，未含 `错误` |

## 3. 变更明细

### 3.1 `输出.错误` 多实参重载

```java
/** 多实参依次拼接后写入标准错误 */
public static void 错误(Object... 部分) {
    System.err.println(拼接(部分));
}
```

复用已有的私有 `拼接`，与 `打印` / `打印行` 行为一致；原 `错误(Object)` 保留。

### 3.2 单元测试

新增 `输出错误多实参依次拼接`：捕获 `System.err`，断言 `输出.错误("错误：", "文件不存在")` 拼接后换行、`输出.错误()` 输出空行。测试总数 12 → 13。

### 3.3 文档校准

- `教程\教程.md` 9.1：改为“十二组用例”，补 `输出（多实参拼接）`；
- `语言规范.md` 规则 9：补 `输出.错误("错误：", 消息)`；
- `速查表.md` 多实参一行：补 `输出.错误`。
