# 第27批优化规格：示例采用最新写法

## 1. 目标

示例目录是新学习者最先照抄的代码。前几批把 `重复 N 次`、插值运算符自动加括号做进了语言，但示例里仍留着旧的三段式 `对于` 和没有运算符演示的插值。本批让三个示例直接用上最新写法，避免“语言支持了、示例却没教”。

## 2. 发现的问题

| 编号 | 位置 | 问题 |
| --- | --- | --- |
| P1 | `示例\中文程序.java:18` | 循环仍写 `对于 (整数 序号 = 0; 序号 < 3; 序号++)`，正是 `重复 N 次` 的典型场景 |
| P2 | `示例\脚本示例.java:6` | 同上，脚本示例里的三段式循环 |
| P3 | `示例\插值示例.java` | 只演示变量与集合插值，没有演示第 24 批修好的「表达式含运算符自动加括号」 |

## 3. 变更明细

### 3.1 两个示例改用 `重复 N 次`

```java
重复 3 次 {
    计数.加一();
}
```

```java
重复 3 次 {
    打印行("第 {序号} 行");
}
```

默认变量 `序号` 从 1 开始，与原三段式输出一致。

### 3.2 插值示例补运算符演示

```java
// 表达式含运算符时自动加括号，不会先拼成字符串
整数 甲 = 2;
整数 乙 = 3;
打印行("和：{甲 + 乙}，积：{甲 * 乙}");
```

新增输出 `和：5，积：6`，直接展示第 24 批修复的优先级行为。
