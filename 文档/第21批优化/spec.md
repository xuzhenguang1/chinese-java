# 第21批优化规格：清掉示例里的英文布尔字面量 + 打印写法再简化

## 1. 目标

把教程与示例里最后一处英文保留字 `true` 改成中文 `真`，并顺手把两处「字符串 + 表达式」的拼接换成更短的打印写法，让学习者看到的代码没有英文残留、也更贴近中文语序。

## 2. 发现的问题

| 编号 | 位置 | 问题 |
| --- | --- | --- |
| P1 | `示例\标准库演示.java` 第 62 行 | `配置.放入("启用", true);` 英文布尔字面量 |
| P2 | `示例\标准库演示.java` 第 65 行 | `数据.转JSON(配置, true)` 英文布尔字面量 |
| P3 | `教程\教程.md` 第 350 行 | 标准库 API 表里写 `转JSON(值, true)`，学习者会照抄英文 |
| P4 | `示例\标准库演示.java` 第 27 行 | `"香蕉库存：" + 库存.取出或("香蕉", 0) + "，键个数：" + 库存.元素数()`，三个 `+`、两层引号，读起来费劲 |
| P5 | `示例\泛型基本类型.java` 第 11 行 | `"苹果单价：" + 单价.取出("苹果")`，同样可以更短 |

`标准库\` 是纯 Java 实现（仓库规则明确不写中文关键字），其中的 `true` / `null` 保持原样，不属于本批范围。

## 3. 变更明细

### 3.1 中文化

| 文件 | 改动 |
| --- | --- |
| `示例\标准库演示.java` | `配置.放入("启用", true)` → `配置.放入("启用", 真)`；`转JSON(配置, true)` → `转JSON(配置, 真)` |
| `教程\教程.md` | API 表 `转JSON(值, true)` → `转JSON(值, 真)`，并补一句「第二个参数为 `真` 时美化缩进」 |

`真` 来自词典组 `true=[真]`（另有 `成立`），转译后与 `true` 完全等价。

### 3.2 打印写法简化

| 文件 | 改前 | 改后 |
| --- | --- | --- |
| `示例\标准库演示.java` | `输出.打印行("香蕉库存：" + 库存.取出或("香蕉", 0) + "，键个数：" + 库存.元素数());` | 先取 `整数 香蕉库存 = 库存.取出或("香蕉", 0);`，再 `输出.打印行("香蕉库存：{香蕉库存}，键个数：{库存.元素数()}");` |
| `示例\泛型基本类型.java` | `打印行("苹果单价：" + 单价.取出("苹果"));` | `打印行("苹果单价：", 单价.取出("苹果"));` |

- 第一处：插值表达式不允许内部出现引号，所以先把带引号参数的调用存进变量，再用插值；比原来的三段拼接短且没有 `+`。
- 第二处：`打印行` 的多实参糖会自动拼成 `+`，实参里的引号与逗号都不影响，直接省掉 `+` 和一层括号。
