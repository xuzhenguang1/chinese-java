## 4. 输出格式（两套实现共用）

`原生 语法` 与 `自举前端.exe 语法` 输出同一单行字段格式：

```
文件|<文件名>
诊断|<错误|提示>|<码>|<行>|<列>|<长度>|<消息>|<建议>
树|<转义后的 AST 全文>
汇总|<文件数>|<成功数>|<错误数>
```

- 每个文件先输出 `文件`；有词法诊断（CJK002 / CJK106）或语法错误时逐条输出 `诊断`；
  解析成功再输出一行 `树`。
- `树` 为 `语法树打印器` 的完整文本转义成单行：`\` → `\\`、`|` → `\|`、
  `\n` → `\n`、`\r` → `\r`、`\t` → `\t`。
- `诊断` 只含 `读取` 产生的词法诊断与 `语法异常`；不含 CJK001 粘连与 CJK101–105 新手提示。
- 文件顺序与现有 `收集文件` 一致（路径字典序）。
- 语法命令退出码恒 0；错误只体现在 `诊断` 与 `汇总` 计数中，便于逐字节对拍。
- `快照` 子命令直接写 `.ast.txt`（UTF-8 无 BOM、`\n` 行尾），文件名去掉 `.java` 后加 `.ast.txt`。

## 5. 自举侧设计

### 5.1 节点模型

- 普通类 + 单继承：`类 节点 {}`，各节点类继承 `节点`。
- 不使用 `sealed` / `permits` / 多接口 record / 模式匹配绑定；打印器用
  `若 (节点 属于 若语句) { 若语句 x = (若语句) 节点; ... }` 分支。
- 节点字段与 `语法树.java` 的 record 分量一一对应，便于逐行对照移植。
- `语法树打印器` 的 `StringJoiner` 改为手写连接，`"  ".repeat(n)` 改为循环追加缩进。
- `Set.of` / `List.of` / `IdentityHashMap` 改为 `集`、`新建 数组清单`，并删除行号旁路表。

### 5.2 语法分析

- 移植顺序：顶层与成员 → 语句 → 表达式 → 类型与基础。
- 回溯（局部变量 vs 表达式、强制转换）继续用异常 + 位置回滚；`语法异常` 携带行、列、消息、建议。
- `期望大于号` 拆分 `>>` / `>>>` 时，用 `数组清单.设定` 替换当前标记。
- `是类型声明起点`、`是增强对于头`、`是括号λ` 等前瞻逻辑逐行移植。
- 运算符优先级、结合性与 `解析二元(最低)` 保持一致。

### 5.3 词表与打印

- `词表读数` 增加 `英文到中文`：关键字组取首个中文词，`若 (!含键) 放入`，与 `词表.java` 的
  `putIfAbsent` 等价。
- `类型文本`、`类型参数文本`、`类型列表文本`、`加修饰` 逐行移植；修饰符中 `@` 开头原样输出。
- 缩进固定两个空格，行尾统一 `\n`，与 `语法树打印器.行` 一致。

## 9. 风险与对策

| 风险 | 影响 | 对策 |

| 原生后端未验证 `属于` + 强转、普通类继承、自定义异常字段 | 节点模型写不下去 | T3 前用最小样例探测；缺口先补运行时/后端，不改对拍口径 |
