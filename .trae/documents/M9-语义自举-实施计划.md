# M9 语义自举（一期：名称解析 + 类型检查）实施计划

## 1. 目标与口径

用中文 Java 在现有单文件 `原生\自举\自举前端.java` 内追加语义层（名称解析 + 类型检查），
与 Java 参考实现 `原生\中间表示\src\中文\原生\中间\语义分析器.java` 逐字节对拍。

- 参考口径：新增 `原生 语义 <根> <文件或目录...>`，按稳定顺序打印「符号表 + 语义诊断」文本。
- 自举口径：`自举前端 语义 <根> <文件或目录...>`，输出同格式、同排序。
- 分期：本期只做名称解析 + 类型检查 + 语义诊断，不生成 MIR；MIR 降级与打印（`原生 中间` 对拍）
  另立 ADR 作为 M9 二期，不在本期承诺。

## 3. 输出格式（新增，单行转义，`|` 分隔）

```text
类|类名|父类|接口数|字段数|方法数
字段|类名|字段名|类型|静态?|只读?
方法|类名|方法名|参数类型1,参数类型2|返回类型|静态?|抽象?
诊断|行|列|码|消息
汇总|文件数|类数|方法数|诊断数
```

- 全部按 `类名` → `字段名/方法名` 升序；参数类型用 `,` 连接；空值写 `-`。
- 诊断按 `行`、`列` 升序；与词法/语法诊断互不混排（语义只报语义错误）。
- 输出前先做词法与语法分析；词法/语法有错时只输出 `汇总|0|0|0|0`（与参考一致）。
