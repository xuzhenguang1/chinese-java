# M10 自举四期（MIR 降级与打印）实施计划

## 1. 目标与口径

用中文 Java 在现有单文件 `原生\自举\自举前端.java` 内追加 **MIR 降级 + MIR 文本打印**，
与 Java 参考实现 `原生\中间表示\src\中文\原生\中间\语义分析器.java` + `中间打印器.java`
逐字节对拍。

- 参考口径：复用现有 `原生 中间 <路径...>`（`前端主程序.打印中间代码`），不新增参考命令。
- 自举口径：新增 `自举前端 中间 <根> <文件或目录...>`，输出与参考同格式、同顺序。
- 本期范围：**教程 01–21**（对象模型与异常，对应路线图 M3 + M4 的语法范围）。
- 22–35 课（标准库内建映射、泛型容器、流与 λ、记录自动方法、密封类、切换表达式）不在本期，
  留待 M11 五期；理由见 ADR-014。

## 3. 输出格式（沿用参考，不新增格式）

```text
程序
  类 <名> [抽象] [枚举] [父 <父类>] [实现 <接口1>,<接口2>]
    字段 <类型> <名>
    静态字段 <类型> <名>
      初值
        <表达式>
    枚举常量 <名>
      <实参表达式>
    构造器 <构造>
      参数 <类型> <名>
      <语句>
    方法 <名> <静态|实例> <返回类型>
      参数 <类型> <名>
      <语句>
```

- 表达式/语句行文本与 `中间打印器` 完全一致（含 `接收者`、`条件`、`则`、`否则`、`真`、`假`、`体` 等固定词）。
- 单文件调用不打印 `// 文件名`；多文件调用每份前打印 `// 文件名`。
- 每份程序末尾输出一个空行（参考 `print(打印()) + println()`）。

## 6. 明确不做

- 教程 22–35：标准库内建映射（清单/字典/文件/流/可选值/比较器）、泛型容器类型文本、
  记录自动方法、λ 与方法引用合成、切换表达式与 `顺序表达式`、`重复 N 次`。
- 解释器、C 后端、LLVM 后端、运行时；不替换生产路径的 Java 语义分析器。
- 多文件共享符号表（与参考一致：逐文件独立降级）。
- 不修改词法/语法/语义三层既有输出与快照，不复制词表。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 降级规则面大（参考 3195 行） | 以 21 课 2193 行快照定口径，ADR-014 列明未覆盖面 |
| 临时变量命名不一致（`__容器0` / `__下标1` 等） | 复刻画 `临时变量(前缀)` 与 `临时序号` 重置时机，以快照为准 |
| 插值解析无正则可用 | 手写扫描，复刻 `分析文本` / `找右花括号` / `跳过字面量` |
| AST 字段不足 | 在自举 AST 内补齐所需字段，保持语法树与语义快照不变 |
| 原生后端限制（接收者重复求值、局部需初始化、字面量禁 `{`） | 沿用 M8/M9 经验：先取局部变量、显式初始化、拼接字符串 |
| 驱动传数组参数被拼接 | 对拍逐文件调用，与 `生成MIR快照.ps1` 一致 |
