# 中文 Java（Java 内核 + 中文关键字）

用中文关键字写 Java，编译后仍是标准 `.class`，任何 JVM 都能运行；中文与英文源码可以混编。

```java
类 问候 {
    入口 {
        字符串 名字 = "小明";
        打印行("你好，{名字}！");
    }
}
```

## 先跑起来

```powershell
# 检查 → 编译 → 运行，一条命令（单文件开发都这样跑）
.\工具\对话\运行.ps1 教程\第01课你好世界.java

# 只检查全部教程的空格、标点与新手易错写法
.\cjc.ps1 检查 教程
```

最小的程序只有一行：

```java
打印行("你好，中文编程！");
```

整份文件只有语句时，`cjc` 会自动补上类与 `main` 外壳（脚本模式）。新建工程用 `.\cjc.ps1 新建 项目 我的工具`，会生成 `pom.xml` 与 `src\main\中文\演示\应用\主程序.java`。

## 最常用的写法

| 想要 | 中文写法 | 等价 Java |
| --- | --- | --- |
| 打印 | `打印行("你好")` / `打印("…")` | `System.out.println` / `print` |
| 多值输出 | `打印行("姓名：", 名字, 年龄)` | 自动用 `+` 拼接 |
| 插值 | `"你好，{名字}"` | `"你好，" + 名字` |
| 入口 | `入口 { … }` / `入口 声明抛出 输入输出异常 { … }` | `public static void main(String[] 参数) [throws …]` |
| 类型 | `字符串` `整数` `双浮点` `布尔` `对象` | `String` `int` `double` `boolean` `Object` |
| 集合 | `清单` `数组清单` `键值表` `链式键值表` `集` | `List` `ArrayList` `Map` `LinkedHashMap` `Set` |
| 建集合 | `数组清单.从("甲", "乙")` / `键值表.从("甲", 1)` | 可变清单 / 不可变映射 |
| 集合操作 | `加入` `取出` `找下标` `设定` `移除` `清空` `元素数` `是空` `整理` | `add` `get` `indexOf` `set` `remove` `clear` `size` `isEmpty` `sort` |
| 映射操作 | `放入` `取出或` `含键` `含值` `键集合` `值集合` | `put` `getOrDefault` `containsKey` `containsValue` `keySet` `values` |
| 枚举操作 | `全部值` | `values` |
| 字符串 | `修剪` `转大写` `转小写` `含有` `以开头` `替换` `取字符` `拆分` `复读` `是空白` | `trim` `toUpperCase` `toLowerCase` `contains` `startsWith` `replace` `charAt` `split` `repeat` `isBlank` |

## 三条硬规则

1. **中文关键字后必须跟空格或标点**：`私有 字符串 标题` 对，`私有字符串标题` 错（CJK001）。
2. **只用能映射到半角的标点**：`，` `（` `）` `：` `；` `！` `？` 可以，`“”` `《》` 不行（CJK002）。`。`、`、` 会自动纠正并提示（CJK106）。
3. **关键字与类型别名是保留词，不能当变量名**：需要时改叫 `实例`、`文本值`、`原字符`、`字节值`、`数量`、`小数`。

`cjc 检查` 还会提示五类新手易错写法（CJK101 字符串 `==`、CJK102 `整理()` 无参、CJK103 `读整数()` 后紧跟 `读行()`、CJK104 循环上界用 `<= 元素数()`、CJK105 整数相除丢小数），只建议、不阻断；确需保留时在该行行尾写 `// 忽略提示`。

## 常用命令

```powershell
.\cjc.ps1 检查 教程                         # 只检查
.\cjc.ps1 检查 --含编译 示例                 # 检查后再编译，暴露类型错误
.\工具\对话\运行.ps1 示例\脚本示例.java      # 检查 + 编译 + 运行，异常栈中文化
.\cjc.ps1 编译 教程 -d 构建\教程             # 编译目录
java "-Dstdout.encoding=UTF-8" -cp 构建\教程 第01课你好世界
.\cjc.ps1 反译 英文源码 -d 构建\反译         # 英文 Java → 中文写法
.\cjc.ps1 新建 项目 我的工具                 # 生成 Maven 中文工程
.\工具\发布\校验.ps1 -含原生                 # 全量回归
```

用 `cjc 运行` 或 `运行.ps1` 启动时，运行时异常的头与栈帧会转成中文（如 `数组越界异常：下标 5 超出长度 3` + 一条建议）；直接 `java -cp …` 启动时仍是 JVM 原文。

## 两条路线

| 路线 | 方式 | 适用 |
| --- | --- | --- |
| A（主线） | `cjc` 源码预处理器：检查 → 转译 → 调标准 `javac` | 任意 JDK 17+，无需改 JDK |
| B（增强） | 给 `jdk.compiler` 打 `Tokens` 补丁，`javac` 原生识别中文关键字 | 需 JDK 25，升级 JDK 后重新打补丁 |

两条路线编译同一份中文源码，行为一致；路线 A 额外提供 CJK001 / CJK002 诊断。近义词集中维护在 `工具\cjc\近义词典.txt`（如 `公有=[公开，公共]`），关键字表只引用组名，`cjc` 加载时自动展开，三种写法都编译为 `public`。

## 词汇从哪来（进阶）

- **关键字表** `工具\cjc\关键字表.txt` 是唯一数据源（v1.6：56 个英文关键字 / 121 个中文词 / 34 个类型别名）；改写后跑 `.\工具\cjc\同步词表.ps1`，再跑 `.\工具\发布\校验.ps1`。
- **方法糖** `工具\cjc\方法糖.txt` 的 `[成员]` / `[声明]` / `[静态]` / `[白名单]` 四个分区决定 `加入` → `add` 这类改写，顺序即匹配优先级；增删糖只改这个文件，不动 `Cjc.java`。
- **近义词**：`.\工具\cjc\词典更新.ps1 -干跑` 先预览，确认后去掉 `-干跑` 即只增不删地写回，并自动同步产物、跑教程编译回归，失败回滚。词源是本地的 `工具\cjc\词林.txt`（约 1.5 KB），无需联网。

## 中文标准库别名（可选）

纯 Java 包装 JDK，不修改 JDK、不依赖 `cjc`，两条路线都可用。

```powershell
mvn -f 标准库\pom.xml package
.\cjc.ps1 编译 示例\标准库演示.java -d 构建\演示 -cp 标准库\target\cjc-stdlib-0.3.0.jar
java "-Dstdout.encoding=UTF-8" -cp "构建\演示;标准库\target\cjc-stdlib-0.3.0.jar" 标准库演示
```

共 10 个别名类：`输出`、`文本`、`数值`、`时间`、`文件`、`集合工具`、`并发`、`网络`、`日志`、`数据`（JSON 编码）。中文源码优先用语法糖；这些别名只在语法糖未覆盖时使用。

## 已知限制

1. `var` 未映射（可用 `--允许推断` 的 `令`/`常量` 间接使用，默认关闭）；`yield` 由 `产出` 转译；`record` / `sealed` / `permits` / `non-sealed` 分别由 `记录` / `密封` / `许可` / `非密封` 支持，均只走转译层。
2. 中文关键字粘连检测是启发式；`cjc.ps1` 与 `中文javac.ps1` 都会执行 CJK001 检查。
3. IDE 的语言服务不认识中文关键字，可能标红，但不影响编译与运行。
4. 原生补丁与 JDK 版本绑定（当前 JDK 25），升级 JDK 后需重新生成。
5. 近义词典须与关键字表同目录；原生补丁与 VSCode 数据由 `同步词表.ps1` 生成，修改词表后需重新运行。
6. 近义词越多，与普通中文标识符重名的概率越高；重名候选应加入 `排除词`（详见 [语言规范](语言规范.md)）。
