# 中文 Java（Java 内核 + 局部中文编程）

保留 Java 的 JVM、字节码、标准库与生态，只把语言**表层**（关键字与标点）改成中文可写。
中文源码编译后仍是标准 `.class`，任何 JVM 都能运行；中文与英文源码可混编。

- 关键字表版本：v1.6（56 个英文关键字 / 121 个中文词 + 34 个类型别名 `字符串`/`对象`/`清单`/`集`/`文件路径`/`扫描器` 等，见 `工具\cjc\关键字表.txt` 与 `工具\cjc\近义词典.txt`）
- 工具链版本：v1.6.2（结构重构 + 标准库去重）
- 验证环境：Windows / JDK 25.0.2 / PowerShell 5.1

## 两条路线

| 路线 | 方式 | 适用 |
| --- | --- | --- |
| A（主线） | `cjc` 源码预处理器：检查 → 转译 → 调标准 `javac` | 任意 JDK 17+，无需改 JDK |
| B（增强） | 给 `jdk.compiler` 打 `Tokens` 补丁，`javac` 原生识别中文关键字 | 需 JDK 25，升级 JDK 后重新打补丁 |

两条路线编译同一份中文源码，行为一致；路线 A 额外提供 CJK001（关键字粘连）/ CJK002（全角标点）诊断。

## 快速开始

```powershell
# 1) 只检查空格与标点
.\cjc.ps1 检查 教程

# 2) 一条命令跑单文件：检查 → 编译 → 运行
.\工具\对话\运行.ps1 示例\脚本示例.java

# 3) 新建中文工程（生成 pom.xml 与 主程序.java，再 mvn package）
.\cjc.ps1 新建 项目 我的工具

# 4) 编译全部 35 课，再运行第 1 课
.\cjc.ps1 编译 教程 -d 构建\教程
java "-Dstdout.encoding=UTF-8" -cp 构建\教程 第01课你好世界
```

`cjc 运行` 与 `工具\对话\运行.ps1` 会把运行时异常的头与栈帧转成中文（如 `数组越界异常：下标 5 超出长度 3` + 一条建议）；直接 `java -cp …` 启动时仍是 JVM 原文。编译期 javac 报错同样会中文化，见 [语言规范](语言规范.md) §7.1–§7.2。

想少写样板代码时，可以用**脚本模式**（整份文件只写语句）、`入口 { … }`（代替 `公有 静态 无 main(字符串[] 参数)`）、**字符串插值**（`"你好，{名字}"`）和**自动导入**（没写 `导入`，或只写标准库导入时自动补 `java.util.*` 等 6 个包），见 [语言规范](语言规范.md) §4.7–§4.10；另可用 `--允许推断` 开启 `令` / `常量` 的类型推断糖（默认关闭，见 §4.11）。对话式开发的约束、模板与流程见 [AGENTS.md](AGENTS.md) 与 `工具\对话\模板\`。

集合与 Stream 也有简写：增强 for 可写 `对于 (名 : 名单)`（自动补 `var`，无需推断开关）；`清单.从` / `键值表.从` / `集.从` 创建不可变集合；`流` 后可接 `过滤` / `变换` / `遍历` / `去重` / `收集`，并配 `收集器.转清单` / `转集` / `拼接`。完整示例见 [教程/第32课集合与流.java](教程/第32课集合与流.java)，规则见 [语言规范](语言规范.md) §4.15–§4.16。

数遍数不用背三段式：`重复 3 次 { … }` 即 `for (int 序号 = 1; 序号 <= 3; 序号++)`，重名时写 `重复 3 次 (i) { … }` 自选变量名，见 [教程/第31课重复循环.java](教程/第31课重复循环.java)、[语言规范](语言规范.md) §4.17。`cjc 检查` 还会顺手提示五类新手易错写法（CJK101 字符串 `==`、CJK102 `整理()` 无参、CJK103 `读整数()` 后紧跟 `读行()`、CJK104 循环上界用 `<= 元素数()`、CJK105 整数相除丢小数），只建议、不阻断；确需保留时在该行行尾写 `// 忽略提示`。

中文关键字后**必须跟空格或标点**：`类 用户 {` 合法，`类用户 {` 非法（会被当成一个标识符）。
近义词集中维护在 `工具\cjc\近义词典.txt`，例如 `公有=[公开，公共]`；关键字表只引用组名 `public=[公有]`，`cjc` 加载时自动展开，三种写法都编译为 `public`。词典可随时增删近义词，无需改关键字表。v1.0 起 51 组、114 词；v1.2 由本地词林补入 10 个，共 124 词；v1.3 采用词林最大档（`=`/`#`/`@` 三类编码、允许单字、`--不消歧`），并把明显别义的词放进 `排除词`；v1.4 删去单字 28 个与跨 3 个以上义类的 9 个（歧义大），并给词源加上自动过滤，共 235 词（184 个近义词 + 51 个组名），平均每个英文关键字约 4.6 个中文写法；第 5 批再删去生僻/语义不准的近义词；第 6 批删去 12 个语义不准的近义词，现为 65 个近义词 + 50 个组名，再加 `抽象` 与 `记录`/`密封`/`许可`/`非密封`/`产出` 6 个单别名，合计 121 个中文词。

## 词典自动更新（可选）

`工具\cjc\词典更新.ps1` 按 `工具\cjc\词典源.json` 取候选词，**只增不删**地合并进词典，再自动运行同步与编译回归；任一步失败即回滚词典与产物。

默认词源是**本地离线**：`工具\cjc\词典源.py` 读《同义词词林（扩展版）》`词林.txt`，无需密钥、无需联网；`词典源.json` 的 `启用` 已设为 `true`。`词林.txt` 已裁剪为 37 行、175 词（约 872 KB → 1.5 KB）：只保留与现有 50 组关键词重叠 ≥2 个词的同义组，行内只留组名与词典内近义词，其余同义组与歧义词全部删除。

```powershell
# 1) 先干跑看清将新增哪些词
.\工具\cjc\词典更新.ps1 -干跑
# 2) 确认后应用（可加 -组名 若 只更新一组）
.\工具\cjc\词典更新.ps1
# 只想看某组会拿到什么
python 工具\cjc\词典源.py 若
```

当前采用**自动过滤后的扩充档**：`本地.参数` 为 `--锚定 --最少重叠 2 --编码 =#@ --上限 16 --最少字数 2 --歧义阈值 3`。四重过滤依次是：

1. `--最少字数 2`：丢弃单字候选（单字在代码里歧义最大）；
2. `--歧义阈值 3`：候选在词林中跨 3 个以上义类（编码前 2 字符）即丢弃；
3. `--锚定 --最少重叠 2`：只从「已含至少 2 个现有近义词」的词林组取词，避免把组名的其它义项带进来（例如 `空` 不会再给出 `天空`、`皇上`）；
4. `词典更新.ps1` 扫描 `教程`/`示例`/`标准库\src` 的中文标识符（先去注释与字面量），与候选重名即自动跳过并打印原因。

剩余仍读起来不相干的词由 `排除词` 收口。

也可以改成 HTTP 接口：把 `词源` 改为 `接口`，配好 `接口`/`方法`/`参数`/`返回路径`/`词字段`（默认模板是 ShowAPI，密钥走 `SHOWAPI_APPID`/`SHOWAPI_SIGN`）。或让 `词典源.py --serve 8080` 起本地服务，`接口` 填 `http://127.0.0.1:8080/`。

更新规则：仅收录 2–6 字纯中文词；跳过自身组名、已属其他组的词、`排除词` 与源码中已有的中文标识符（自动扫描，命中即打印跳过原因）；与既有标识符冲突时编译回归也会失败并自动回滚。`--锚定` 只取与现有近义词重叠达标的词林组，`--最少重叠` 控制重叠门槛；`--编码 "=#@"` 控制收录的编码末位，`--上限` 控制每组取词数量，`--最少字数`/`--歧义阈值` 控制自动过滤；`{词语}` 为组名占位、`{环境:变量名}` 为环境变量占位；`查询词` 可把某组换成更合适的查询词。v1.4 的 `排除词` 共 339 项：`列`、`此刻`、`状态`、`类别` 与教程/标准库标识符重名，其余为词林给出的明显别义（代词、字体名、物态、当铺/典当、假期、`-化` 词、成语、租借/农转非，以及 `真人真事`/`联袂`/`道貌岸然` 等新增 27 项）。

## 中文标准库别名（可选）

纯 Java 包装 JDK，不修改 JDK、不依赖 `cjc`，两条路线都可用。

```powershell
mvn -f 标准库\pom.xml package
.\cjc.ps1 编译 示例\标准库演示.java -d 构建\演示 -cp 标准库\target\cjc-stdlib-0.3.0.jar
java "-Dstdout.encoding=UTF-8" -cp "构建\演示;标准库\target\cjc-stdlib-0.3.0.jar" 标准库演示
```

共 10 个别名类：`输出`、`文本`、`数值`、`时间`、`文件`、`集合工具`、`并发`、`网络`、`日志`、`数据`（JSON 编码）。中文源码优先用语法糖；`输出`、`文本`、`数值`、`集合工具`、`文件` 是兼容别名，仅在语法糖未覆盖时使用。

## 已知限制

1. `var` 未映射（可用 `--允许推断` 的 `令`/`常量` 间接使用，默认关闭）；`yield` 由 `产出` 转译；`record` / `sealed` / `permits` / `non-sealed` 分别由 `记录` / `密封` / `许可` / `非密封` 支持，均只走转译层、不进原生补丁；`strictfp` 自 v0.3 起映射为 `严格浮点`。
2. 中文关键字粘连检测是启发式；`cjc.ps1` 与 `中文javac.ps1` 都会执行 CJK001 检查。
3. IDE 的语言服务不认识中文关键字，可能标红，但不影响编译与运行。
4. 原生补丁与 JDK 版本绑定（当前 JDK 25），升级 JDK 后需重新生成。
5. 近义词典须与关键字表同目录；原生补丁与 VSCode 数据由 `同步词表.ps1` 生成，修改词表后需重新运行。
6. 最大档（`=#@` + 单字 + `--不消歧`）的词义范围仍比人工挑选宽（如 `同步` → 同时/一起/一并、`真` → 诚/诚实、`这` → 此/这时）；明显别义已由 `排除词` 拦掉，仍觉得不贴切时继续往 `排除词` 里加，或去掉 `--不消歧`、把 `--编码` 退回 `"="`。
7. 近义词越多，与普通中文标识符重名的概率越高；`词典更新.ps1` 会用教程编译回归拦截，重名候选应加入 `排除词`。
