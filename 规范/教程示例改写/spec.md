# 规范：教程与示例全量改用对话式新语法

## 1. 目标与范围

把 `教程\第01–30课.java` 与 `示例\*.java` 统一改写为当前已实现的对话式语法糖，同时保留每一课的教学点、注释与显式类型。

- 范围：`教程\` 下 30 个 `.java`、`示例\` 下 8 个 `.java`、`教程\教程.md` 中的对应代码片段、`CHANGELOG.md` 一条记录。
- 不在范围：`标准库\`、`工具\`、`构建\`、`发布\`；不新增语言特性；不改 `Cjc.java`。
- 约束：不使用 `令` / `常量`（`--允许推断` 默认关闭）；不依赖 `中文.标准库.*`；所有文件必须能通过普通 `检查` / `编译`。

## 2. 统一改写规则

### R1 脚本化（纯 main 文件）

条件：文件最外层类除 `main` 外没有其他成员。

处理：删除 `类 X {`、`公有 静态 无 main(字符串[] 参数) {` 与其对应的收尾 `}`，只保留注释 + 导入 + 语句。Cjc 会自动包裹外壳。

### R2 入口化（含其他成员的文件）

条件：外层类还包含方法、嵌套类、枚举、接口等，或文件有多个顶层类。

处理：仅把 `公有 静态 无 main(字符串[] 参数) {` 替换为 `入口 {`；其余类结构、缩进、收尾 `}` 原样保留。

例外：`示例\标准库演示.java` 的 main 带 `声明抛出 …`，`入口` 无法表达 throws，保持原样不改。

### R3 println 糖

`System.out.println(` → `println(`，但只在该语句位于语句开头（`{` / `}` / `;` 之后）时改写。

例外（保持 `System.out.println`）：
- `情形 … -> System.out.println(…)` 的箭头分支（第19课 3 处）；
- lambda 体 `名称 -> System.out.println(…)`（第29课 1 处）；
- `System.out.print(读回)`（第27课，本就不是 println）。

### R4 字符串插值

把“字面量 + 简单表达式 + 字面量”的整条拼接改为 `"前缀{表达式}后缀"`。允许的表达式：标识符、字段、数组下标、方法调用、`Math.xxx`、`参数.length`、`异常.getMessage()` 等，且不含引号、逗号、冒号、花括号、反斜杠、换行。

保持拼接（不插值）的情形：
- 表达式内有字符串字面量，如 `星期.valueOf("周三")`、`库存.get("苹果")`、`解析("42")`；
- 表达式带逗号参数，如 `求和(3, 4)`、`Files.readAllLines(目标, StandardCharsets.UTF_8).size()`；
- 复杂算术 / 强制转换 / 三目，如 `(双浮点) 班级总分 / 班级.size()`；
- 教学点本身就是拼接：第03课、第24课（`StringBuilder` 与 `join`）保留原样。

### R5 保留项

- 每课头两行注释（课号 / 目标）保留，可在第01课补一段等价完整写法作对照注释。
- 全部显式类型、变量名、方法名、类名、字段名不更名。
- 输出文案不改（只改写法），保证运行结果与原来一致。

## 6. 风险与回滚

- 风险：插值误伤含引号 / 逗号的表达式 → 一律按 R4 保持拼接；改完后用 `检查` 暴露语法问题。
- 风险：脚本化后行号错位 → Cjc 已有 `stripOneLineBreak` 处理，验证时留意诊断行号。
- 回滚：所有改动仅限 `.java` 与文档，可用 `git diff` 逐文件回退；不触碰工具链。
