# 中文 Java 教程（35 课）

## 1. 环境准备

## 2. 五分钟跑通第一个程序

在仓库根目录（本教程目录的上一级）执行，一条命令完成检查、编译与运行：

```powershell

```

预期输出：

```
你好，中文编程！
```

想看全部课程是否通过检查、并编译到 `构建\教程`：


只看单个文件也可以：

仍保留英文的只有 JVM 强制的入口方法 `main`；`toString` / `equals` / `hashCode` 在声明处也写中文（`转文本` / `等于` / `哈希码`），由 `cjc` 还原成 Java 同名方法。

入口要声明异常时，不用写整段 `公有 静态 无 main(字符串[] 参数) 声明抛出 …`：

```java
类 演示 {
    入口 声明抛出 输入输出异常 {
        打印行("需要处理文件时这样写");
    }
}
```

增强 for 还可以**省略元素类型**（自动补 `var`，无需 `--允许推断`）：

```java
清单<字符串> 名单 = 清单.从("张三", "李四", "张五");
对于 (名 : 名单) { 打印行(名); }
清单<字符串> 张姓 = 名单.流().过滤(s -> s.以开头("张")).收集(收集器.转清单());
张姓.遍历(s -> 打印行(s));
```

完整示例见 `第32课集合与流.java`；`遍历` 在 `.` 之后优先按成员糖处理，不会被当成 `对于` 的近义词。

计数循环也不用背三段式，写 `重复 N 次` 即可（默认变量名 `序号`；怕重名就自选名字）：

```java
重复 3 次 {
    打印行("第 {序号} 行");
}
重复 名单.元素数() 次 (i) {
    打印行(名单.取出(i - 1));
}
```

完整示例见 `第31课重复循环.java`。

链式条件可以直接写 `否则若`，不用在 `否则` 和 `若` 之间加空格：

```java
若 (分数 >= 90) {
    打印行("优秀");
} 否则若 (分数 >= 60) {
    打印行("中等");
} 否则 {
    打印行("待努力");
}
```

`否则若 (` 和 `否则若(` 都会还原成 `else if (`；只有语句开头（前一个符号是 `}` / `;` / `{`）且紧跟 `(` 时才生效，所以叫 `否则若` 的变量不受影响。

### 4.1.1 集合写法（只有一套）

集合统一用 `cjc` 的类型别名 + 成员糖，不再有第二套兼容写法：

| 写法 | 底层 | 何时用 |
| --- | --- | --- |
| `清单.从(...)` | `List.of`，不可变 | 只读常量集合 |
| `数组清单.从(...)` | `new ArrayList<>(List.of(...))`，可变 | 需要继续 `加入` / `移除` |
| `键值表.从(...)` | `Map.of`，不可变 | 只读映射 |
| `链式键值表` + `放入` | `LinkedHashMap`，保持插入顺序 | 需要增删映射 |

常用方法：`加入` / `取出` / `设定` / `移除` / `元素数` / `是空` / `整理` / `放入` / `取出或` / `含键`。

记法建议：

1. **只记一套**：`清单` 是 `List`，`数组清单` 是 `ArrayList`，`键值表` 是 `Map`，`链式键值表` 是 `LinkedHashMap`；方法名一律用 `加入` / `取出` / `元素数` / `是空` / `整理` / `放入` / `移除`。
2. **需要标准库时**才写 `导入 中文.标准库.*`：`文本` / `数值` / `时间` / `文件` / `集合工具` / `并发` / `网络` / `日志` / `数据` / `输出` 共 10 个别名类；只做集合与文件读写时，`cjc` 的自动导入已够用。只写标准库导入时，`cjc` 仍会自动补 6 个 JDK 包；若另外写了 `java.*` 或第三方导入，则不再自动补。
3. **标准库类名后面的方法保持原样**：`数值.转文本(42)`、`文本.去空白(…)`、`集合工具.填充(…)` 中接收者就是类名，`cjc` 不会把它们改成 `toString` / `trim` / `fill`。但把同一个名字声明成变量后（`字符串 文本 = " 丙 ";`），它就按变量走糖，`文本.修剪()` 会正常变成 `trim`。

## 6. 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `错误 CJK001 … 缺少空格` | 中文关键字与名称粘连，如 `新建数组清单` | 在关键字后加空格：`新建 数组清单` |
| `提示 CJK106 … 已自动纠正` | 写了句号 `。` 或顿号 `、`，已自动改成 `;` / `.` / `,` | 无需处理；想严格报错时加 `--严格标点` |
| `错误 CJK002 … 不支持的全角标点` | 用了 `“”` `《》` `『』` 等无法映射的标点 | 换成 `"` `'` `<` `>` `[` `]` |
| `找不到符号: 类 新建数组清单` | 同一处粘连的另一种表现（原生模式无 CJK001） | 同上，补空格；提交前跑 `cjc 检查` |
| `需要';'` / `需要'{'` | 把 `throws` 写成了 `抛出` | `抛出` = `throw`（主动抛出）；方法签名上的 `throws` 用 `声明抛出` |
| 泛型位置报类型错误 | 基本类型别名不能直接作泛型实参 | 直接写 `清单<整数>`、`键值表<字符串, 双浮点>`，`cjc` 会自动换成包装类型；`整数包装` 等旧写法仍兼容 |
| `类 X 是公共的，应在 X.java 中声明` | public 类名与文件名不一致 | 保证文件名 = public 类名 |
| 运行时提示找不到主类 | 入口方法不是 `main` | `main` 是 JVM 约定，不翻译 |
| `提示 CJK101` | 用 `==` 比较字符串，只比较引用 | 改用 `甲.等于(乙)`；判空仍用 `== 空` |
| `提示 CJK102` | `名单.整理()` 没有参数 | 用 `集合助手.排序(名单)`，或传入比较器 |
| `提示 CJK103` | `读整数()` 之后紧跟 `读行()` | 中间补 `输入.读行();`，或统一改用 `读行() + 整数.解析(...)` |
| `提示 CJK104` | `序号 <= 名单.元素数()` 会多走一轮 | 改成 `<`；确要包含末尾写 `<= 名单.元素数() - 1` |
| `提示 CJK105` | `5 / 2` 这类整数相除会丢掉小数 | 写 `5.0 / 2`，或先强转 `(双浮点) 甲 / 乙` |

这些 `提示` 不影响编译和退出码，跑 `cjc 检查` 时顺便提醒；确实需要整数除法（如按十位分档）时，在该行行尾写 `// 忽略提示 CJK105` 即可关闭本行提示。

三条最容易踩的规则：

1. **中文关键字后必须跟分隔符**（空格或括号、分号等），这是词法硬约束。
2. **不要用中文关键字作变量名或方法名前缀**（`类用户`、`返回结果`），规范层面禁止。
3. **字符串、注释里的内容不翻译**，可以放心写中文。

补充：全部近义词集中在 [工具/cjc/近义词典.txt](../工具/cjc/近义词典.txt)（v1.6 起 50 组、116 词，其中 65 个近义词 + 50 个组名；另有 `抽象` 与 `记录`/`密封`/`许可`/`非密封`/`产出` 6 个单别名，合计 121 个中文词），关键字表只引用组名，如 `public=[公有]` 会自动展开为 `公有`/`公开`/`公共`。可以随时在词典里增删近义词，`cjc` 下次运行即生效，不必改关键字表；`若`/`如果`/`假如`/`若是`/`倘若`/`要是`（`if`）、`否则`/`不然`/`要不然`（`else`）、`新建`/`实例化`/`创建`（`new`）、`整数`/`整型`（`int`）、`真`/`成立`（`true`）等写法都来自词典。此外还可用 `情况`（`case`）、`预设`（`default`）、`互斥`/`协同`（`synchronized`）、`执行一次`（`do`）等写法；单字与高歧义词（如 `型`、`裹`、`干`、`回`、`碰`）已在 v1.4 删除，剩余明显别义收进 `排除词`；v1.6 又删除了 12 个语义不准的近义词（`种类`/`包装`/`封装`/`个人`/`保障`/`维护`/`概念化`/`持续`/`实验`/`真正`/`虚假`/`搀假`）。此外，`java.lang` 常用类型有中文写法：`字符串`（`String`）、`对象`（`Object`），基本类型的包装类统一用「X包装」（`整数包装`=Integer、`长整数包装`=Long、`双浮点包装`=Double、`布尔包装`=Boolean 等），可直接用在泛型里，如 `键值表<字符串, 对象> 配置 = 新建 链式键值表<>();`、`异步结果<整数包装> 平方 = 并发.提交(线程池, () -> 25 * 25);`（v1.5 起类型别名共 34 条，其余常用类与异常见 §4.1）。

词典也支持自动扩充（v1.1 起，v1.2 启用，v1.4 起自动过滤）：默认词源是本地的 [工具/cjc/词林.txt](../工具/cjc/词林.txt)（《同义词词林》扩展版，已裁剪为与现有 50 组关键词相关的 37 行 175 词，由 [工具/cjc/词典源.py](../工具/cjc/词典源.py) 查询，无需密钥，配置在 [工具/cjc/词典源.json](../工具/cjc/词典源.json)），先运行 `.\工具\cjc\词典更新.ps1 -干跑` 预览，确认后去掉 `-干跑` 即**只增不删**地写回，脚本会自动同步产物并编译教程，失败则回滚。候选会先经四重自动过滤：单字（`--最少字数 2`）、跨 3 个以上义类（`--歧义阈值 3`）、语义锚定（`--锚定 --最少重叠 2`，只取含现有近义词的词林组）与源码中文标识符重名（自动扫描 `教程`/`示例`/`标准库\src`）。

### 6.1 运行时错误也会说中文

编译通过只是第一步。用 `.\工具\对话\运行.ps1`（或 `.\cjc.ps1 运行 <文件>`）启动程序时，异常头和栈帧也会转成中文，并在首条异常后给一条建议：

```text
程序运行出错（线程「main」）：数组越界异常：下标 5 超出长度 3
    建议：检查下标范围：0 <= 下标 < 数组.长度（集合用 元素数）。
    位置：异常测试.main（异常测试.java 第8行）
```

| 英文异常 | 中文 |
| --- | --- |
| `NullPointerException` | 空指针异常 |
| `ArrayIndexOutOfBoundsException` | 数组越界异常 |
| `StringIndexOutOfBoundsException` | 字符串下标越界异常 |
| `ArithmeticException` | 算术异常 |
| `NumberFormatException` | 数字格式异常 |
| `InputMismatchException` | 输入类型不匹配 |
| `NoSuchElementException` | 没有更多元素 |
| `IOException` / `FileNotFoundException` | 输入输出异常 / 文件未找到异常 |
| `UnsupportedOperationException` | 不支持的操作异常 |
| `ClassCastException` | 类型转换异常 |
| `ConcurrentModificationException` | 并发修改异常 |
| `StackOverflowError` | 栈溢出错误 |

消息里的高频英文片段也换成了中文（`Index 5 out of bounds for length 3` → `下标 5 超出长度 3`、`/ by zero` → `除数为 0`）。注意：只有 `cjc 运行` / `运行.ps1` 这条路径会中文化，直接用 `java -cp …` 启动时仍是 JVM 原文。

## 7. 原生关键字模式（可选）

`工具\原生补丁\中文javac.ps1` 是另一个命令入口，内部先按 `cjc` 规则转译再编译，所以省略返回类型（`公有 加一() {`）在这里也能用：

```powershell
.\工具\原生补丁\中文javac.ps1 -encoding UTF-8 -d 构建\教程 教程\第01课你好世界.java
java "-Dstdout.encoding=UTF-8" -cp 构建\教程 第01课你好世界
```

- 支持 `-encoding`（统一按 UTF-8 读取）、`-d`、`-cp`/`-classpath` 与源码文件/目录；
- 原 `jdk.compiler` 补丁（`.\工具\原生补丁\编译.ps1` 生成）仍保留：它只把中文词映射成关键字，无法调整语序或插入 token，因此启动器统一走转译；
- 提交前仍建议执行 `.\cjc.ps1 检查 <目录>`。

扩展位于 [工具/vscode-中文java](../工具/vscode-中文java)，采用**语法注入**方式：不改变 `.java` 的语言模式，只在标准 Java 语法之上把中文关键字与全角标点着色。

### 8.2 代码片段

在 `.java` 文件中输入以下前缀并回车：

| 前缀 | 展开内容 |
| --- | --- |
| `类` | 类骨架 |
| `主方法` | `入口 { … }`（完整写法为 `公有 静态 无 main(字符串[] 参数)`） |
| `若` / `否则` | 条件分支 |
| `对于` / `遍历` / `当` | 计数循环 / 增强 for / while |
| `尝试` | `尝试 / 捕获 / 兜底`（捕获默认 `输入输出异常`） |
| `枚举` / `接口` / `构造器` | 类型骨架 |
| `打印` / `打印行` | `打印(...)` → `System.out.print`；`打印行(...)` → `System.out.println` |
| `新建` / `导入` | 对象创建 / 导包（默认 `导入 中文.标准库.*;`） |

> 说明：扩展在高亮与补全之外，还会调用 `cjc 检查`，把 CJK001（空格粘连）与 CJK002（全角标点）显示为编辑器内诊断（红波浪线 + 问题面板），来源标记为 `cjc`；诊断消息里会附上「建议：…」（CJK001 给出补空格后的写法，CJK002 给出可直接替换的半角字符），`提示 CJK101–CJK106` 以黄色警告显示。触发时机有两处：
>
> - **保存时**：保存 `.java` 文件立即检查，由 `cjc.checkOnSave`（默认开启）控制；
> - **输入时**：停止输入 500ms 后检查（防抖，检查的是编辑器里的未保存内容），由 `cjc.checkOnType`（默认开启）控制；快速连续输入不会堆积进程。
> 自 0.12.0 起，命令面板执行「中文 Java：运行当前文件」（或编辑器右键菜单）会在集成终端调用 `工具\对话\运行.ps1`，自动保存当前文件后运行；交互式程序可直接在终端输入。
> 自 0.2.0 起，扩展还提供中文关键字**补全**（输入前缀后选择，自动补一个空格）与**悬停说明**（鼠标停在关键字上显示对应英文与用途）。
> 若同时安装 Java 语言扩展，其诊断会把中文关键字标红，属预期现象，不影响编译与运行。

## 9. 中文标准库别名（可选）

别名模块位于 [标准库](../标准库)，用纯 Java 包装 JDK，不修改 JDK，也不依赖 `cjc`。包名 `中文.标准库`。

| 类 | 对应标准库 | 常用成员 |
| --- | --- | --- |
| `输出` | `System.out` / `System.err` | `打印`、`打印行`（多实参自动拼接）、`错误`、`格式` |
| `文本` | `String` 工具 | `是否为空`、`是否空白`、`去空白`、`分割`、`重复`、`连接` |
| `数值` | 数值转换 | `转文本`、`是整数` |
| `时间` | `LocalDate` / `LocalDateTime` / `DateTimeFormatter` | `今天`、`此刻`、`时间戳`、`格式化`、`相差天数`、`加天数` |
| `文件` | `Files` / `Path`（UTF-8） | `读文本`、`写文本`、`存在`、`建目录`、`列举`、`大小`、`删除` |
| `集合工具` | `Collections` | `填充`（排序等请用 `集合助手.*`） |
| `并发` | `java.util.concurrent` | `固定线程池`、`单线程池`、`执行`、`提交`、`取结果`、`关闭`、`休眠`、`当前线程名` |
| `网络` | `java.net.http.HttpClient` | `取`、`取文本`、`取状态码`、`下载到` |
| `日志` | `java.util.logging` | `取`、`控制台`、`信息`、`警告`、`错误`、`调试`、`设置级别` |
| `数据` | JSON 编码 | `转JSON(值)`、`转JSON(值, 真)`（第二个参数为 `真` 时美化缩进） |

> 推荐：中文源码优先用语法糖（`打印行`、`算术.*`、字符串成员糖、`整数.解析`、`集合助手.*`、`文件助手.*`）。上表中的 `输出`、`文本`、`数值`、`集合工具`、`文件` 是兼容别名，仅在语法糖未覆盖的方法上使用。

构建与使用：

```powershell
# 1) 构建（产物：标准库\target\cjc-stdlib-0.3.0.jar）
mvn -f 标准库\pom.xml package

# 2) 用 cjc 编译带别名的中文源码（-cp 指定依赖）
.\cjc.ps1 编译 示例\标准库演示.java -d 构建\演示 -cp 标准库\target\cjc-stdlib-0.3.0.jar

# 3) 运行
java "-Dstdout.encoding=UTF-8" -cp "构建\演示;标准库\target\cjc-stdlib-0.3.0.jar" 标准库演示
```

原生关键字模式同样可用：

```powershell
.\工具\原生补丁\中文javac.ps1 -encoding UTF-8 -cp 标准库\target\cjc-stdlib-0.3.0.jar -d 构建\演示-原生 示例\标准库演示.java
```

示例源码：[示例/标准库演示.java](../示例/标准库演示.java)。别名为**可选依赖**：不使用它时，源码与运行方式和前面 30 课完全一致。

### 9.1 单元测试

```powershell
mvn -f 标准库\pom.xml test
```

测试类为 `标准库\src\test\java\中文\标准库\标准库测试.java`，覆盖清单、键值表、文本、数值、时间、文件（`@TempDir`）、集合工具、并发、网络（本地 `HttpServer`）、日志、数据（JSON）、输出（多实参拼接）十二组用例。测试源码由标准 `javac` 编译，不能写中文关键字，集合直接使用 JDK 的 `ArrayList` / `LinkedHashMap`。

### 9.2 在 Maven 工程中依赖

`标准库` 先在本地安装一次：

```powershell
mvn -f 标准库\pom.xml install
```

之后在普通 Maven 工程里直接声明依赖（无需 `cjc` 插件额外传类路径，Maven 会自动传递）：

```xml
<dependency>
    <groupId>cjc</groupId>
    <artifactId>cjc-stdlib</artifactId>
    <version>0.3.0</version>
</dependency>
```
